# 自然技术研究共用自然语言回答流程

本批承接用户同意的定稿 #214、方案 #215 与批准 #216。规则版本为 `technical-shared-narrative-v1`。自然技术问题使用已有公司研究执行器的取数、证据与 v3 自然语言正文；用户意图仍记为 `technical_research`。真实模型技术回答质量尚未在新增10题上评估。

## 入口与保存

具名技术问题、最近成功研究对象的技术追问、名单单只技术研究和共用结果的指标编辑进入相同流程。路由只选择执行器，不授予取数或发布权限；trace（本地运行元数据记录）分别保存意图与实际入口，允许 `technical_research` / `company_research` 组合。2a意图评估按意图分类，不因执行器共用而改成公司意图。

公司服务未配置时，自然技术和名单技术仍使用旧执行器。原结构化 Python、CLI、技术 API、已存在的技术身份/指标待澄清任务和旧保存记录保留；知识、取消、重置、冲突及完整新任务仍按原优先级处理。

研究主体的语义类型与保存载体分开：仅技术领域的主体为 `technical`，其 `scope` 可携带 `ProductPlan`（程序确认的研究条件）。历史查看、继续研究与编辑按实际载体取结果，不假定 technical 必须对应旧 `confirmed`。过期后，核对当前目录、来源通过才继承条件重新取数，不复用旧行情。失败或取消后的当前结果失效，不能恢复更早的结果。

## 程序保存的范围限制

`product_scope.py` 收拢领域肯定/否定、“只看”及技术请求判断。`ProductScope` 保存领域限制、严格指标组合和排除项，随计划和待澄清条件传递，取数前再校验；默认空约束兼容原构造，公开计划只在受限制时增加 `scope`。

| 问法 | 程序约束 |
| --- | --- |
| 只看SMA3 / 只看RSI和MACD | 仅用明确组合，不为参考计划自动增加ATR |
| 只看技术面 / 仅技术 / 纯技术面 | 不读取公司资料、财报、新闻和公告；未指定指标时仍可使用原默认组合 |
| 不是只看技术面，还要基本面 | 按新的肯定范围扩大，不把否定的“只看”当成限制 |
| 无限定的RSI7并计算止盈止损 | 保留原ATR14依赖、公式和预算 |
| 再加RSI2 | 继承股票、日期、期限及其他限制，仅授权新增指标；非技术结果首次新增时不激活尚未研究的默认指标 |

已请求具体指标或排除均线时，价格背景不额外提供MA20/MA60，只保留原始价格事实及明确请求的均线。最新收盘、涨跌幅和原始高低点使用同一份已校验日线，不增加行情获取。

`coverage`只列实际研究领域；公开`excluded_domains`与网页“按要求未研究”单独说明排除范围，不能把排除财报说成财报缺失。明确请求的指标部分不可用时，技术覆盖为`limited`，保留有效证据和指标缺项；未指定指标的旧默认组合覆盖口径保留。

## 指标编辑与澄清

`product_indicator_edit.py`复用原完整命令解析、参数和重复检查，不复制指标公式。“再加”仅归一为完整添加命令，不截取合法前缀而吞掉其他要求。

唯一目标修改后重新取数，分配新请求编号，再进行一次正文合成；不再调用模型理解编辑。多个窗口目标先给`indicator_edit_ambiguous`，编辑上下文放入原`product_pending`，不新增顶层待澄清类型。选择须完整匹配，证券、来源、目录和15分钟有效期仍核对。重复、非法参数、删除最后指标和未支持复合命令不查询、不回默认组合。

## 正文、研判、计划分别接收

纯读数和历史关系使用v3正文，不强制评级；方向、未来走势和买卖问题沿用现有决策识别。引用归属、数字来源绑定、逐句删除、至多一次修正及程序事实兜底全部复用。

严格SMA3没有ATR时，合法正文和有证据的评级可保留；计划返回`risk_atr_not_requested`。失效说明仍须通过原检查，没有合法说明时不能靠缺失计划补位。无计划证据的“止损10元”即使等于本轮收盘也删除，A3数字核对规则不放宽。

## 基线和评估

v6以冻结v5为父，同39场景117轮逐字段核对：31轮、382条字段变化，其余86轮不变，见[逐轮差异](request-routing-technical-deltas.md)。v1～v5、A2/A3差异及三个原观察器不改。独立技术目标在实现前编写，脚本支持共用工具后才形成差异，不把脚本失败录为成功。

原40场景59步新增版本差异，保留问题、质量和安全要求，固定模型调用68次。原20题离线研判仍20/20、44次调用（两题准备各省一次）。这些仅证明人工脚本契约。原304题2a语料和标签不改；规则登记保留B2历史摘要，新规则拒绝旧阈值锁及跨版本参照。

人工演示支持原五日技术问题的共用正文、原图表和保存结果解释，固定HTTP演示从4次模型方法调用降为3次。决策演示继续展示完整v3结构；严格范围缺MA20时用已有收盘参考，不要求执行器扩范围。数据与研判均为人工设定。

本批不发起付费调用；10题技术真实评估按第二批另开方案。不接入模型路由分类器，不改变评级、ATR公式、数值容差、期限或调用预算。

## 第二批：技术题评估和小修

新增独立的 [technical-answer-v1 评估](technical-answer-evaluation-design.md)，10题、14轮、4道多轮题，题库和人工标注为草稿。每轮6次、整题6乘轮数，总上限84次；可接受显式90次额度并把有效预算收紧到84次。取数入口逐领域记账，包括失败尝试；准备轮同样检查范围。正文、删句、完整逐稿失败码、截断、调用及费用分开记录，未知不填零。真实质量仍待 Claude 合入后运行及人工复核。

v3组装对同股重复驱动因素作保守去重，计入删除句数并单列去重数量；提示要求不同驱动讲不同因素。指标编辑不会把临时依赖ATR14变成用户指定；自动移除后，范围允许的后续买卖问题可重新计算ATR，严格指标仍不补。证券匹配变化时补齐中文提示。评级、价位公式、A3数字容差及路由不变。
