# 从指标报告到自然语言研究答复

日期：2026-10-24。本增量改变网页主回答，不另建 Agent，不增加交易权限。

## 问题与数据流

旧模型主要提取参数、提出工具调用、选择指标关系；研究阶段没有收到原问题。最终文字由程序拼接事实、关系模板和四维综合，展示投影不可用时又回退整份报告。因此“预测下一步方向”得到的是读数清单。

新流程：

```text
原问题 → 模型理解 → 程序核对股票、日期、指标与来源
  → 原问题 + 已确认参数 → 模型工具提议 → 严格参数比对
  → 一次行情读取与确定性计算
      ├─ 计算字段不可用：简短说明不能判断，不发最终模型请求
      └─ 可用：模型回答问题、给条件性方向与观察条件
                  → 关系、请求绑定、段落引用与格式检查
                  → 网页正文 + 折叠的数据、图表与报告
```

人工/未经验证的开发 CSV 不能支持真实股票判断，即使短周期指标能计算。5条人工日线配默认指标时，主回复说明真实数据和历史长度两项缺口。人工模式固定截止日来自 `development_fixtures.REFERENCE_DATE`，不代表最新行情。

## 答复契约

自然入口最终输出 `research-response-v1`，包含 `request_id`、`instrument_id`、实际最新 `trade_date`、1–8项 `claims` 及三项 `paragraphs`。

- 每项claim继续使用 `evidence_id`、`relation`、`value`，从本轮可用关系表原样复制。
- 三段固定角色为 `answer`、`outlook`、`watch_for`，每段包含 `text` 与 `evidence_ids`，先回答问题，再给有前提的方向和成立/失效条件。
- 每段1–600字符，总JSON不超过8,000字符；提示模型总计约200–350汉字。引用非空、无重复，且来自已经核对的所选关系。
- 额外字段、重复JSON键、代码围栏、错股票/日期/请求、无效引用、反向关系、不完整对象均拒绝，不自动修复或重试。
- 本版精确数字留在程序数据视图；正文不接收额外数字，只允许请求中指标的标准标签，如 `SMA(20)`。数字规则是格式约束，不能证明中文数量或推论正确。
- 明确格式入口和旧离线关系模型继续支持 `indicator-explanation-v1`，旧JSON不被冒充成自然语言答复。

## 检查范围与取舍

复用关系验证器，检查当前请求、完整事实、依赖、单位、相邻日期及原精度比较，而不是只看引用ID是否存在。段落引用转换为完整事实ID；换掉请求或结果后会重新核验。任一新协议检查失败，拒绝整段模型正文。

**引用正确不等于段落正确。** 模型仍可能错误解释事实、夸大信息、提出没有依据的倾向。当前没有通用自由文本语义验证，也没有验证预测能力。正文标为“模型解读”，范围是 `request_and_relation_claims_checked_prose_semantics_not_verified`；`answer_validation` 仍为 `not_performed`。

允许模型说“当前偏强，但只有守住某参考位置才可能延续”，不允许把研究意见当作保证、胜率、收益承诺、目标价或已执行交易。没有新闻/基本面工具时不能假装已经查询。真实语言质量和相关性需要独立人工/模型评估，不能由契约测试推断。

## 公共接口与预算

API新增 `conversation`：来源 `model/application`、请求绑定、三段以内正文及引用记录。数据不足、错误、人工模式、停止和模型不可用时返回简短的应用答复。

旧 `answer` / `display_answer` 继续保留程序报告，供诊断与旧客户端使用；`report.fields` 保留原精度和缺失状态。前端优先检查和显示 `conversation`，React文本节点不执行HTML。坏答复显示简短降级说明，不再回退成整面报告或重新请求模型。图表、证据、证券背景、完整报告和执行记录默认折叠。

知识和有限保存结果追问维持旧契约；没有实现任意长对话、自由知识问答或新闻查询。终端和明确格式工具仍保留原报告/关系输出。

没有新增模型请求：自然初始请求最多3次模型/1次分析，股票澄清续接最多2次模型；计算字段全不可用时不发最终解读。取消、超时、额度和迟到输出继续遵守 `TurnControl`。

网页启动配置把单次输出上限设为1,500 tokens，以容纳正文与引用；通用 `DeepSeekConfig` 的512默认值及整轮24,000已观察tokens阈值不变。上限不是实际花费、硬计费限制或质量保证。

## 启动与数据模式

更新后重启Python服务，在没有请求运行时刷新页面；旧内存会话失效。真实研究不能继续用 `--demo` 或 `--data synthetic`。配置好 `.env` 和有效本地证券目录后，在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m trading_companion.api_server --provider deepseek --data tencent --port 8765
```

该命令可能计费，本轮开发未执行。目录缺失/过期时先按[证券目录说明](security-directory-refresh-design.md)刷新，不要当成模型密钥错误。来源固定于启动配置，不从对话静默切换，不自动降级到人工数据。

## 代码与验证

- `research_response.py`：新契约、复用关系校验、段落与引用检查、简短数据就绪答复。
- `agent.py`：保留原问题、自然语言指令、重新核验，复用既有预算。
- `research_intent.py` / `research_session.py`：澄清后不丢失原问题，不向公共会话元数据导出原问题。
- `api.py` / `api_service.py` / `api_server.py`：公共答复与输出上限。
- `frontend/src/{presentation.ts,ResponseContent.tsx,App.tsx}`：绑定检查、正文优先、附件与安全降级。
- `tests/test_research_response.py`：17项离线场景，包括HTTP/幂等、原问题续接、错误关系/上下文/数字/引用/格式、人工/无数据、超时/取消/额度。
- `frontend/tests/conversationResponse.test.tsx`：18项测试，包括正文优先、坏结构/绑定、HTML转义与折叠诊断。
