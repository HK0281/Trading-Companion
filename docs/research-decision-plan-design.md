# 参考研判与 ATR 条件计划

2026-10-29 A 批：公开回答升级 v3，正文与评级分别接收，有限格式和数值容差见[自然语言回答设计](natural-research-narrative-design.md)。本文件的 ATR 公式、用途与条件约束不变；下文 v2 整体拒绝/字面期限要求仅为旧协议记录。

2026-10-29。用户已同意提案 #147，实施方案 #149 经 #150 批准。本文描述本次待审核实现，未代表真实模型质量或历史预测效果已通过验证。

决策问题如“平安银行现在能买吗”“预测一下走势”进入公司研究的 `decision` 目标。普通基本面、新闻、知识、纯历史走势以及原“那止盈止损呢”历史风险情景追问继续使用原流程。具名问题通过证券目录确定身份；省略股票的追问需有效公司结果，无结果、结果过期、单数指代对应多家公司或明确新问题缺对象时先澄清。路由仍是规则，不调用新的分类模型。

期限默认未来20个交易日。交易日计数独立限制为1～366，不转换自然日或推导结束日期；显式周/月表达保留原单位。未来期限不授权未来行情查询。取数尊重“只看”和否定领域；禁用技术面、ATR或计划后不补造价位。

## 数据和公式

`trade_plan.py`复用原历史风险情景的同请求日线、最新收盘、ATR、单位和依赖检查。原 `risk-scenario-v1` 算法与默认两倍目标保持不变，新方法版本为 `atr_reference_plan_v1`：

- E 为最新有效历史收盘价，A 为同一天有效 ATR，默认止损距离1.5A。
- S 为 E−1.5A 按0.01元研究网格向上取整；R=E−S。
- T1 为 E+1.5R 向下取整到分；T2 为 E+2.5R 向下取整到分。
- 实际盈亏比分别为 (T1−E)/R、(T2−E)/R，向下保留六位小数。

使用精确十进制计算，跨 JSON 边界保留字符串。要求0<S<E<T1<T2；缺失最新 ATR、零波动、无效数值、股票/日期/单位不符或舍入后重合均不可用。不改用固定百分比、短周期、旧数据或另一股票填补。支撑压力仍为观察候选，不混入价格公式。

`trade-plan-v1` 的展示精度约定：`values.atr` 在全部计算完成后按 `ROUND_HALF_UP` 四舍五入为固定四位小数；公开计划、`plan_display` 模型计划证据及网页均使用这一展示值。内部止损、目标和盈亏比继续使用未截短的原始 ATR 与收盘价，原数值事实也不改写。前端通用十进制校验允许最多18位整数、12位小数，因此固定四位 ATR 可直接解析。收盘/入场参考补齐两位小数（10.4 显示为10.40）；若来源本身有分以下精度，则保留原值，避免展示舍入改变 E 的含义。

| 用途 | 对应评级及方向 | 展示 |
| --- | --- | --- |
| conditional_entry | 买入/增持，偏多 | 入场、止损、两档止盈、实际盈亏比 |
| wait | 持有，偏多/震荡 | 上下观察价位，触及后重新评估 |
| holding_exit | 减持/卖出，震荡/偏空 | 假如已持有的收盘参考和退出观察位；空仓观望 |

不推断持仓、成本或账户盈亏，不生成做空计划。买入计划后续收盘≤S 时失效并重评；退出/等待触发位只用于重评。所有价位是按历史波动构造的条件参考，不是预测目标，不保证成交、止损或收益；未计费用、滑点、跳空和交易限制。

## 回答契约与检查

决策回答为 `product-research-answer-v2`，普通回答保留v1。原段落与证据字段外，新增逐股票的 `decisions` 及应用生成的 `trade_plans`。模型仅选择 `plan_id`，不能创建计划或改变参数。计划编号绑定请求、证券、方法和用途；引用还需属于最终发给模型的同轮上下文。

每个研判包含证券、状态、评级、方向、期限、把握、2～4条带引用的理由、带引用的失效说明及计划编号。期限照抄应用值；评级和方向需满足上表。把握仅高/中/低，展示“模型自评，未经历史校准”。公开不可用状态有固定原因，不用默认持有/震荡替代缺失意见。模型可以指出实际缺失的领域，不能把未请求的领域自动当作必需资料。

正文、理由与失效说明共享引用归属和词面数字检查，继续拒绝收益保证、HTML/链接、输出注入和自编概率。新价位标签还要与所选计划字段对应；失效阈值由程序生成。检查不证明每句因果描述、模型方向或目标触达正确。

同次调用产生正文和研判，沿用每轮及会话预算；只针对字段或已有证据关联问题最多修正一次。编价、保证收益等不触发修正。模型失败时显示研判未形成，合法程序计划仍可展开；原计划或依赖遭篡改则不显示价位。取消与预算停止继续由原控制器处理，不发布迟到答案。

上下文在原上限内优先保留完整候选计划证据和可用同比事实。模型选择表仅含编号、证券、用途、状态和原因码；完整价格及来源在优先保留的证据中，公开计划仍含完整参数、依赖及条件。这样三股九份候选不会因重复展示元信息耗尽预算。不能因截断只留下编号或半个价格表。可选快照写入时重建检查计划，旧记录不迁移、不回填；历史查看和请求重放不重新取数、不重新调用模型。

## 网页和人工演示

网页显示逐股票结论卡片、可展开依据与失效说明、用途匹配的价格表、实际行情日期和数据性质。买卖评级是参考意见，系统不持有账户状态。

`--demo`或网页 Dev Mode 下输入“平安银行现在能买吗”，固定人工模型会生成买入/偏多/低把握的示意回答；它是专门设定的演示结论，不是根据 ATR 推算出来的方向。`data/decision_daily_bars_synthetic.csv`包含额外人工日线供 ATR14 计算，最后五天与原短样本相同，文件有独立摘要核验。非技术资料在此演示中标记不可用，不联网补齐。

当前演示包含完整 v3 结论、当前情况、3条依据、3行关键价位、三种情景与操作倾向，并经正式校验后显示。宽领域问题实际请求了公司资料、财务、新闻和公告；缺少这些领域使整轮仍为“部分可用”，回答顶部会列明缺项。前端样例从真实演示入口生成，维护命令见[自然语言回答设计](natural-research-narrative-design.md#验收范围)。
