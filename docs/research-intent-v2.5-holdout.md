## 文件与版本绑定

候选指纹与新增运行器/测试/说明文件的指纹分开存放，校验时合并并核对完整源文件清单。这样不需要预填包含锁本身的未来提交号，也不制造源码摘要引用自身的循环。实际运行提交必须是候选的后代，文件及指纹必须完全吻合、工作区必须干净；运行开始后 HEAD、锁摘要和源文件都不能再变。旧 v2.4 锁及运行器不修改。

公开通过报告的提交、计数及原始字节校验值作为事前证据快照存入候选摘要；不要求 Git 忽略的旧报告文件在新检出或 CI（自动验证环境）中仍然存在。运行依赖的公开文件及源文件则逐项重核。

## 默认只读计划

以下命令由 Claude 在审核提交后传入封存路径执行。没有封存路径默认值，不搜索目录；本实现的开发验证只使用合成题库。

```powershell
.\.venv\Scripts\python.exe -X utf8 -B evaluation_tools/evaluate_research_intents_v25_holdout.py --sealed-corpus <Claude显式提供的路径> --expected-sha256 99a5e163cb7840a1f9e135a68578da8ff096185c3efc3fae33262944debc5a6e --plan-only
```

省略 `--plan-only` 仍是同一只读模式。先核对锁和公开记录，再以最多 2000000 字节的有界读取校验指定文件精确字节 SHA 和 96 行。任何 JSON 解码和题干访问之前，SHA 必须同时匹配参数、锁及冻结记录。默认不解码题目，不读取题干或标准答案，不构建目标前置、不调用候选本地前置、不评分、不读取凭据、不联网、不占用运行机会。公开冻结记录及公开源码的核验不涉及封存题目。

输出 `sealed_json_decoded=false`、`context_preflight.status=not_run`、`ready_for_live=false`、当前工作区/目录状态及全部冻结预算/门槛。元数据就绪不代表已完成 96 题的构建检查。

最多 120 次目标请求，每次最多 1500 输出 token（模型使用的文本计量单位），合计输出上限 180000。默认不解码题干，因此**输入 token 上限和费用估算均未知**。正式前置检查后，可按全部消息和工具结构估算输入上界并包括重问；费用按“输入 token×运行时输入单价＋输出 token×输出单价”估算，单价须使用一致单位，缺失输入用量或单价不按零计。计划 JSON 保留这行估算方法，供 Claude 向用户说明。

## 显式运行与一次性占用

在上述命令添加 `--live` 才进入运行路径，两种模式互斥。正式命令不提供模型、锁、题数、预算、运行目录、续跑或重置覆盖项。

1. 要求工作区干净、锁一致、运行未被占用；先验证原始字节，再解析同一份已验证字节，核对唯一题号及全部冻结计数。
2. 在禁网、禁凭据和禁目标理解/评分的环境中，完成 96/96 题的只构建检查。用中性问题构建已审核前置，不借题干选择替代状态；任何题不能构建都不开始运行，不跳题缩分母。
3. 全部通过后重核身份，原子创建固定 `.agentbus/evaluation-runs/research-intent-v2.5/holdout/` 和按封存 SHA 标识的数据使用记录，再加载评估凭据和模型。只有 Claude 执行真实封存计划和运行。
4. 目录一旦占用，即使后续凭据、网络、写盘失败或进程中断，也不删除、不换目录、不补跑。占用记录是本地防误用措施，不是防篡改证明。
5. 每题及每次传输前重核提交、锁、源清单/指纹和封存字节；报告写入前后也重核。任何漂移中止，晚期中止覆盖可能已写出的通过报告。

目标请求前先同步写盘预留计数；诊断、逐次完成、逐题结果和最终状态也同步保存。`attempts.jsonl` 记录每次请求及重问，`rows.jsonl` 记录逐题结果，`reserved.json`、`completed.json` 或 `aborted.json` 记录状态。未知响应和用量保持未知，中止后的未运行题继续列入完整分母。进程在写盘中被强制终止时，以持久占用和账本为准，不能仅因缺少最终报告就重开。

## #420 批准的调用策略例外

冻结原文中的“每题一次、最多96次、无重试”及其指纹原样保留。锁独立登记批准消息 #420 和有效例外：**每题最多 2 次、全局最多 120 次且包含重问，本地题零目标调用**。前置替身调用另计。

沿用候选完整行为：仅工具参数 JSON 格式失败可原消息重问一次；首次保留四种已审核本地修复，第二次只允许 `unquoted_scalar`（单处文字裸值补引号）。网络、超时、拒绝、中断、工具结构或语义失败不重问，不允许第三次；共享时限、取消及已观察 token 额度不重置。新封存工厂显式使用 sealed 诊断作用域，失败参数最多保存10000字符，不记录 HTTP 正文或凭据。

## 判定与报告

- 全部 96 题至少 92 题的 14 字段联合全对。
- 实现期间未用于调参子集初始仍为 96 题，至少95%，即至少92题；作者/审核者见过与实现调参暴露分开登记。
- 语义子集 S=79 按冻结 gold 的 `zero_intent_calls=false` 选定，至少76题全对，不能按实际成功调用数缩分母。
- n≥4 的族至少 `ceil(0.8n)` 全对；更小的族仍逐族报告，不新增必须全对规则。
- 规则共同可观测字段不退步、可测红线零违规；不可测执行检查单列未测。

以上来自冻结记录。失败、无效、未测保留完整分母；原样+原标注、规范化+原标注、规范化+批准标注三列并列，主门槛采用第三列。新检验题不套用旧开发题修订。原样列保留格式修复前/首次重问前失败；本地修复、重问、实际请求、前置调用、返回模型、用量及未知用量分别报告。
