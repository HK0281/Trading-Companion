# 多指标分析服务与证据契约

日期：2026-10-16（America/Los_Angeles）

## 本轮范围

M1b 将已经完成的七类纯计算组合为一个可独立调用的研究服务：验证请求、取一次历史序列、计算、返回逐字段状态、初始化信息、确定性关系及事实标识。新增契约独立于原 `AnalysisResult`，保留单 SMA API 和行情 CLI 的默认值、状态含义与输出。

本轮不调用真实模型，不实现自然语言路由、模型工具循环、自由文本回答检查、会话或总截止时间。服务接收由应用构建的数据源对象；这不是允许模型传 Python 对象、文件路径或 URL 的工具接口。随后新增的[受控工具层](research-tool-design.md)只接收受限结构参数，由程序构建数据源；本服务接口保持不变。

开发分工延续 ProductManager 明确范围、Engineer 实现与单元测试、CodeReviewer 只读复审、UserProxy 独立运行验收。协作子智能体不改变产品采用单个受控研究 Agent 的架构。

## 接口与请求校验

公开入口为：

```python
from trading_companion.multi_analysis import (
    IndicatorSpec, MultiIndicatorRequest, analyze_indicators,
)

spec = IndicatorSpec("sma", window=20)
request = MultiIndicatorRequest(
    instrument_id="000001.SZ",
    start_date=...,
    as_of_date=...,
    indicators=(spec,),
    source="tencent",
)
result = analyze_indicators(source, request)
payload = result.to_dict()
```

契约放在 `multi_contracts.py`，服务放在 `multi_analysis.py`；服务模块重新导出常用公开类型。只读工具注册与供应商工厂留给下一阶段。

默认指标为 SMA20、SMA60、EMA20、MACD(12,26,9)、RSI14、BOLL(20,2)、ATR14、量能20，共8个实例。显式只请求 SMA3 就只计算该项，不附加默认组合。内部依赖不重复占用实例名额。

在读取数据之前检查：

- 完整股票标识与所选数据源的代码覆盖，日期类型及先后顺序。
- 区间含首尾最多366个自然日；不静默截断，也不隐式读取区间外预热。
- SMA/EMA 周期1–120；RSI/ATR/BOLL周期2–120；MACD满足 `2≤fast<slow≤120`、`2≤signal≤60`；BOLL倍数有限且 `0<k≤4`。量能周期本轮服务层选择1–120，与均量的正整数口径一致；这是对PRD未明确列出范围的实施补充。
- 指标参数不能包含布尔值、非有限数或不属于该类的字段。规范化后去重，最多12个不同实例，保留用户首次指定顺序。
- 请求来源与配置来源一致；配置中的股票和在线日期范围必须匹配，避免实际读入另一股票或额外历史。
- CSV 需要由开发者显式启用 `allow_development_csv=True`，仅用于开发测试。真实生产工具不开放该模式。默认标签是开发样例、真实性/复权未知；本仓库人工样例额外用受信配置 `CsvDailyBarSource(path, is_synthetic=True)`，输出醒目标识“人工样例/非真实行情”。该标记是开发者配置，不是程序自动验证了文件的真实性或合成来源。

本服务要求显式日期；自然语言入口的“默认截止上海前一天”和“含截止日365个自然日”留给后续应用层，不能让模型自行确定日期。对应365日区间的起点应是截止日减364天。

## 数据读取与失败边界

每个请求只执行一次 `read_daily_bars()`，全部指标使用同一份选定日线。适配器内部跨年可能产生多次 HTTP 请求；一次数据源读取不等于一次网络请求。开发CSV可以包含更多日期，读取后严格按请求区间截取，不使用区间外记录初始化指标。

行情类型、数值、股票和时序未通过校验时，整体返回无效行情；不拼接部分行冒充成功。空来源与没有匹配记录分别记录原因。数据源错误不自动重试、不切换供应商，结果不复制原始供应商错误体、路径或凭证。

计算仅使用请求区间内的日线，不排序、不补日期、不把过去值填到当前缺项。日期过滤不等于严格历史时点可得；获取时间不等于历史发布时间。不复权跳变、腾讯上游量额舍入等限制进入结果警告。

某个指标出现可预期的数值计算错误时，仅该实例标记计算错误，其他有效实例保留；不将错误伪装成历史不足。未知编程错误不能被一个兜底 `except Exception` 隐藏为正常业务结果。

## 多层状态与日期对齐

| 层次 | 含义 |
| --- | --- |
| 数据状态 | 行情有效、无数据、来源失败或无效数据 |
| 计算状态 | 请求的数值字段全部可用、部分可用、全部不可用或未执行 |
| 字段与关系状态 | `available`、`insufficient_history`、`undefined`、`calculation_error` |

每个字段包含日期、值、单位、状态、原因、所需/实际记录数及适用的缺少数量。结果保留完整对齐序列，最新结果严格取实际最后一条日线；不能悄悄使用更早的有效字段。数据状态使用 `ok/no_data/source_error/invalid_data`，计算状态使用 `complete/limited/unavailable`；源失败或无数据时没有计算结果。

计算完成情况按请求的数值字段判断；自动生成的关系独立表达可用性。例如 SMA3 第3条首次有值，价格比较可以成立，均线斜率或交叉仍可能缺少前一点。`synthesis_allowed`只表达至少一个计算字段可用，排除单独的原始成交股数；它不是买卖评级或任意推断的授权。任何后续解释都必须检查具体字段和关系状态，而不是只看总体完成。

关键场景：

- 30条请求默认组合：SMA60缺30条，MACD的DEA/柱缺4条；DIF及其他就绪字段仍可用。
- RSI14/ATR14最早第15条可用，BOLL20/含当日均量第20条可用，相对前20条均量倍率第21条可用。
- 前均量为0时倍率为 `undefined`；正常分母下当日0量为可用的0。
- 全部请求指标不可用时仍能展示可信行情及缺项，不生成综合趋势结论。模型解释能力本轮尚未接入。

## 初始化元数据

递推指标提供实际计算起始日、种子方式、首个可用日、初始化后递推次数和相关周期。EMA 使用前n条SMA；RSI/ATR使用n个变化或TR均值加Wilder递推。

`required_bars`表达最早可能就绪的记录门槛，`first_available_date`表达本次序列里字段实际首次为 `available` 的日期，二者不等同。量能倍率即使已有n+1条，若此前均量为0仍未定义；直到某条基准为正才产生实际首个可用日，没有有效倍率时该日期保持 `None`。

MACD分别描述快EMA、慢EMA、DEA三个组件：默认首个慢EMA/DIF是第26条，首个DEA/柱是第34条。30条时慢EMA已递推4次，DEA尚未初始化；34条时DEA递推0次，35条才递推1次。不能用同一个次数描述所有组件。

组件保留各自递推次数；起点提示按其相关最长周期3倍判断，MACD的DEA还需表达快慢EMA等依赖，而不能只看signal周期。该阈值不是数学收敛证明或指标可靠性保证；计算起点改变仍可能改变结果。算法版本与参数都属于计算身份的一部分。

## 确定性关系与最小证据

关系由程序使用未舍入数值生成：

- 收盘价与SMA/EMA位置、均线变化、价格与均线交叉；不同请求均线之间的位置与交叉。
- MACD的DIF/DEA关系及交叉、柱值相对前一点的变化。
- RSI相对30/70区间，BOLL相对三轨的位置和相等边界。
- ATR只比较波幅增减或不变，不给涨跌方向。
- 相对量能与1的比较；不把它解释为资金净流入、机构买入或盘中量比。

上穿需要前一差值≤0且当前>0；下穿需要前一差值≥0且当前<0。只有当前点有效时交叉缺项；当前仅等于基准时不算穿越。

数值事实与关系事实使用请求内唯一标识，能够定位请求、股票、日线日期、指标实例/参数与字段。关系保存具体依赖，涉及变化或交叉时包含相邻前一点的事实，所有依赖都能在事实集合中解析。不可用字段不伪造数值事实。跨均线关系能够定位两个不同指标实例。

完整历史字段留在 `indicators[].series`，证据集合只保留最新和紧邻前一条的数值，以及本次最新关系的依赖；`evidence_scope`明确为 `latest_and_immediately_previous_record`。`to_dict()`必须可用严格JSON序列化，不留下 `date` 对象、NaN或Infinity。事实引用存在不等于已验证模型文字含义；未来M2仍需约束解释类型并检查方向、数字和日期。

## 验收

1. 默认30条、显式SMA3、各初始化边界、不同起点、量能零值与未定义。
2. 单次读取；全部非法请求在读取前拒绝；同源同区间，不隐式预热或换源。
3. 交叉边界、全精度比较、缺前点、跨均线以及关系依赖完整性。
4. 源失败、空数据、损坏数据、单项计算异常与脱敏返回。
5. 截止日与实际最新日分离，追加或修改未来日线不改变截面结果。
6. 严格JSON、开发CSV提示、README可运行示例和原SMA API/CLI回归。
