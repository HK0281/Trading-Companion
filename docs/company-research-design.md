# 多维公司研究

## 目标与参考

将自然对话扩展为一般知识、技术面、基本面、公告新闻、候选比较与风险情景。用户问题决定收集哪些领域，不要求用户填写技术参数。数值计算由程序完成，模型负责理解与有证据的解释，系统没有交易执行工具。

参考 [TradingAgents](https://github.com/TauricResearch/TradingAgents) 的领域分析、工具路由与综合机制，以及 [TradingAgents-CN](https://github.com/hsliuping/TradingAgents-CN/tree/v3.0) 的中文市场适配。采用独立数据契约和受控编排，不复制角色数量或整套依赖。CN 仓库包含混合许可，尤其不能将其 app/frontend/core 当作统一开源代码搬入本项目。参考的是公开架构模式，本项目自行实现。

## 1. 开放金融知识

`open_knowledge.py` 接收完整教学问题，一次无工具模型调用解释概念、方法和假设。固定指标定义继续走原来的零模型快捷路径；具名股票、行情和新闻研究不走通用知识入口。

API 的保守教学路由不依赖证券目录，因此目录过期不会阻止解释 PE/PB。多轮研究结果与待澄清条件保留；共享原有会话锁、幂等、调用额度、取消和截止控制。

回答检查包括 JSON 格式、长度与部分范围规则。它不验证自由文本的全部金融事实或语义。模型失败返回简短提示，不假装完成行情查询，也不输出未通过检查的草稿。

## 2. 数据领域

公司资料、财务、新闻与公告拥有独立的 request/section/evidence 契约。发布时间、日期精度、报告期、采集时间和历史修订限制分别保存。接口失败或无覆盖不影响其他领域，HTTP 200 本身不代表有效数据。

供应商当前快照按发布时间过滤，不能称为完整的历史版本数据库。没有发布时间的公司资料仅能作为明确标记的当前背景，不能用于历史截面。

当前公开数据适配器使用固定东方财富端点取得公司资料、最新可用财务报告与公告；巨潮公告可显式选择，已验证映射仅覆盖深市。所有返回必须匹配证券标识、字段与时间窗口，拒绝跳转、过大响应、错误 JSONP 和缺失关联。公司资料的当前背景与历史报告分开，不以采集时间代替发布时间。

新闻默认显式配置为新浪个股资讯列表。页面必须与公司名和代码对应，每条标题也需要包含公司名或代码；只取有限一页、最多五条合格资料，保留分钟精度，不冒充新闻全文。东方财富新闻仍可显式配置用于诊断，失败不会暗中改走另一个来源。新浪与东方财富是不同领域的预先配置，不是行情失败后的自动替代。

2026-10-25 对中际旭创做小规模真实公开源探测：公司资料五项、财务五项及公告五条成功；东方财富新闻返回了错误 callback，正确拒绝，保留其他领域的可用结果。离线测试使用固定响应，不依赖外网，也不把真实探测外推为长期可用性。

## 3. 风险情景计算

`risk_research.build_risk_scenario` 接收已校验的同一份日线分析，以最近历史收盘价为假设做多参考点。默认止损距离为 1.5×ATR，目标距离为原风险距离的两倍。优先本轮 ATR14，缺失时不借用旧点或悄悄换周期。程序用 Decimal 在 0.01 元网格上对止损向上、目标向下取整，再计算实际风险比例和收益风险比。

这是给研究回答引用的假设情景，不涉及账户、持仓、真实成本或任何委托。停牌、跳空、费用和可成交性未在公式中建模，不能承诺止损一定成交。缺少 ATR 或事实依赖不一致时返回不可用，不让模型自编目标价。
