# K 线与指标可视化

2026-10-30 指数2a：新增独立 `index-chart-v1` 日线和 `index-chart-interval-v1` 周线，复用绘图交互；点位轴及读屏使用“点”，未经核实的量为空、不画零量柱。文字周证据仅用完整周，图表末周可以显示未完标记。指数小时线暂关闭，股票下述小时能力保持。见[指数研究设计](index-research-design.md)。

初版：2026-10-22。2026-10-30 按用户要求实施 #244 A/B 步：精简回答附加区、默认互动日线，增加周线与腾讯 1小时/2小时线。图表不新增研究工具、模型调用或交易权限。

## 1. 数据从哪里来

```text
原日线分析 → MultiIndicatorResult
  ├─ 事实报告与受限关系 → 公共 answer / report
  └─ build_chart_projection → result.chart → 浏览器校验 → 原生 SVG
```

日线图和文字使用同一次分析，不另外查询“最新行情”，也不在浏览器重算指标。周线与小时线的独立取数和重算规则见第7节，仍绑定原研究日期与来源。图表不是模型生成的图片，坐标由已校验数字计算。

已有接口返回可选 `chart` 日线快照及 `chart_capabilities` 来源能力声明；新增周期走下文独立接口。公共 `parameters` 明确携带来源，包括开发 CSV；工具提议协议不变。图表内部 `request_id` 与报告研究编号一致，不是 HTTP 请求的幂等编号。

## 2. DTO 与检查

`research-chart-v1` 成功响应包括：请求编号、股票、请求区间、来源、复权、真实性、获取时间、current/saved上下文、保存时间、`bars`和`series`。

- `bars` 按日期递增，包含date/open/high/low/close/volume，只导出本次返回的记录。
- `series` 包含指标实例、参数、算法版本、字段、单位、起点敏感提示，以及与bars逐项对齐的values/statuses。
- 先复用事实报告的请求与最新证据检查，再检查每个历史行的日期、字段、状态、所需/实际条数和空值。不重新计算指标，也不声称任意历史数字已独立核实。
- `available` 必须有有限数值；其余状态保持null。成交量单位是股，量比与指数点不得混入价格轴。图表数字绝对值最多1e15，此限制不改变研究计算契约。
- 最多366条日线、12个指标实例、48个字段序列。完整紧凑UTF-8 JSON最多256KiB；超限整张图不可用，不静默截断、抽样或删指标。
- 固定失败码：`chart_context_invalid`、`chart_data_unavailable`、`chart_integrity_mismatch`、`chart_payload_limit`。失败仅导出版本、状态和代码，不回显异常、路径或未核实编号。

前端仍做运行时检查：绑定报告编号、股票/区间/来源/指标参数，检查日期、算法、单位、数值及数组长度。TypeScript不替代这项检查。可选图表非法时只显示固定降级提示，不把已确认研究答案改成“网络响应未确认”，不触发模型重试。

## 3. 当前、追问与历史

初始研究从本轮 `research_result` 导图，标记current。已接受的结果追问和显式历史查看，再通过原 `saved_result()` 校验保存结果的有效期、身份及配置；只附与回答研究编号一致的快照，标记saved。数据保留原保存时间，界面简短标明“已保存快照，非新分析”。

该重查是本地验证与深复制，不取行情、不调模型。历史不是新的编辑基准；新研究失败后不能自动附旧图，只有明确查看历史才可取得旧快照。知识、歧义、取消、过期和无保存结果不借机展示旧图。附加快照或图表投影出错，不抹掉已经确认的文字回答。

图表和其余公共结果一起进入原幂等缓存；重复同编号取回原快照，不更新获取时间或重做分析。返回对象深复制，调用者不能修改缓存中的图表。

## 4. 展示与交互

回答附加区只保留图表，默认直接显示；正文、段落依据、研判卡与价位计划保留。移除附加技术证据表、全局研究依据、证券状态与交易日历、完整报告入口；相应后端数据契约和校验不变。图表支持：

- 日K线、独立成交量区；红/绿/灰表示当日收盘相对开盘，不是相对昨收。
- SMA/EMA/BOLL价格叠加，可按实例开关。
- RSI、MACD各字段、ATR及量能各字段单独选择，独立坐标轴；MACD柱值以零为基线。
- 最近30/60/120条或全部，默认60条；缩小窗口时将所选记录限制在新窗口内。
- 鼠标悬停、触屏横向拖动选择最近蜡烛，操作时才显示纵横十字线和浮层；默认不遮挡图表。指针离开或触摸结束/取消后隐藏，键盘聚焦时可以继续查看，失焦后隐藏。鼠标点击产生的焦点不会让浮层在离开后常驻。
- 浮层使用紧凑的名称/数值两列，日期下按“开、高、低、收、量”逐行显示，缺项为“—”及原因，不补零、不换行、不提供内部滚动条。始终保留已开启价格线中的桌面前3条、窄屏前2条，以及所选副图；其余显示“另有 N 条线”。可关闭部分叠加线查看其余读数。浮层根据选中位置切边，指针可穿透，不妨碍继续选蜡烛。极大或极小的读数用科学计数法保持紧凑，仍保留最多7位有效数字。
- 叠加线开关、图例、浮层和副图选项使用短名称，如SMA20、BOLL 上轨、MACD DIF、RSI14、成交量均量(20)；内部指标编号只用于绑定。相同指标有多套参数时以BOLL(20,2)、MACD(12,26,9)等常用写法区分；单位放在坐标标题与读数中，不拖长下拉选项。
- 图表可用 Tab 聚焦，左右键逐条移动，Home/End 选择区间两端。读屏播报仅包含日期与收盘；指针移动不持续播报。触屏捕获在抬起、取消或失去捕获时结束，保留页面纵向滚动。窄屏条数/副图紧凑同排；周期按钮旁的价格叠加标签局部横向滚动，不使页面横向溢出。
- 一行来源、复权与“历史日线，非实时”；人工样例和未核验CSV醒目标注。移除日期滑块、独立行情数字框、指标读数表、颜色/区间长说明和采集详情折叠区。

只对实际记录等距排列，不补周末或缺失日期，也不凭缺日推断停牌。指标null断线；只有一个可用点时画点，不填0或跨缺项连线。价格线的显示舍入不改变研究数值。历史点没有新增fact ID，最新证据仍保留在原报告数据中。

选择原生SVG，是因为当前数据量有明确上限、交互有限，不需要引入完整交易图表库、CDN或额外服务。目前没有实时订阅、任意区间加载、拖拽缩放、复权切换或图形形态预测。容器宽度变化时调整SVG坐标，指针按实际显示尺寸换算，索引与十字线均限制边界；375px窄屏控件换行、浮层内收。使用样式表定位浮层，兼容禁止内联样式的内容安全策略。图表读数显示7位有效数字，不改变原结果精度。

## 6. 仍然存在的边界

256KiB限制是单张图紧凑JSON大小，不是Python对象或整个API响应的内存上限。图表随每会话至多20条幂等记录保存，最多32会话；新增内存负担仍只适合本机开发，不是生产容量设计。页面至多40条记录，当前每张合法图直接渲染；没有为旧图引入虚拟列表，也不等于有持久化或账户配额。

真实源当前不复权，CSV复权未知；除权、拆分等可能造成价格跳变。图表模块不识别公司行动，不补证券状态/交易日历，不证明真实行情或投资表现。初版之后的公司研究、筛选等功能另见[模块进展](module-progress-2026-10-26.md)，不属于本图表批次。

## 7. B步：周线和按需小时线

`GET /v1/sessions/{session_id}/chart?research_id=<报告研究编号>&interval=1w|60m|120m`

复用 Bearer 令牌、同源和会话到期检查。查询只接受研究编号和周期，拒绝额外股票、日期、条数或来源参数。服务端在当前会话未退休的完成记录中解析已验证单股日线快照；不能使用聊天请求编号、别的会话编号、多股结果或已重置记录。`chart_capabilities` 绑定同一研究编号，前端据此禁用不支持的周期，服务端独立检查能力。

能力声明仅在HTTP返回的深复制对象上附加，不写回服务层聊天记录；原聊天重放与历史路由观察保持原样。图表代次单独记录，聊天内“新对话”等重置也会使旧图表失效，不改变原聊天重放规则。

| 来源 | 日线 | 周线 | 小时线 |
| --- | --- | --- | --- |
| 腾讯支持的沪深 A 股 | 原报告快照 | 同轮日线聚合 | 点击时取腾讯 m60，重算60m/120m |
| AKShare / 东方财富 | 原报告快照 | 同轮日线聚合 | 暂不可用，不自动改用腾讯 |
| CSV / 开发 | 原报告快照，保留真实性标记 | 同轮聚合，保留真实性标记 | 禁用，零分钟网络请求 |

AKShare 当前 SDK 固定15秒等待并完整读取 JSON，不能下传8秒截止及512KiB限制；因此按 #267/#268 暂禁该源小时线，不用线程等待包装来声称底层请求已经停止。

新增周期使用独立 `research-chart-interval-v1` 数据传输对象，携带周期、上海时区、真实 `start_at`/`end_at`、实际覆盖、来源、复权、真实性、获取时间及研究绑定。柱包含 `complete` 标记；日线仍为 `research-chart-v1`，没有放松旧契约。浏览器校验版本、绑定、时间端点、单位、参数、字段、数组及256KiB大小，失败只降级图表。

周线复用 `technical_insights.group_daily_weeks` 的周一分组，首周周一起点早于原请求开始则省略。开取首、收取末、高低取极值、量求和；不补节假日，不按五条记录猜完整周。周日边界晚于原快照截止日的末周保留，标明“本周未完（截至快照日期）”；原研究仍只使用已完成周线。

腾讯小时线只访问固定 HTTPS `ifzq.gtimg.cn/appstock/app/kline/mkline?param=<symbol>,m60,,320`，无翻页、重试、重定向或换源。按 #248 实测契约读取 `data.<symbol>.m60`：时间、开、收、高、低、量及两个忽略字段。10:30/11:30/14:00/15:00 为结束标签，分别对应09:30–10:30、10:30–11:30、13:00–14:00、14:00–15:00。科创板 `sh688` 原量为股，其他支持沪深板块为手并乘100；输出整数股。原始全批先校验，乱序、重复、错误端点、周末、未来、非法价格/量整批拒绝，再截取原研究日期窗口；空交集明确不足，不拿最新行情代替旧窗口。2小时只合并同日上午或下午的完整配对，缺配对整批不可用，不影响60m。

原始响应最多512KiB/320柱；连接、响应头和每次读取前传入剩余时间，读取后复核总8秒协作截止。不是用后台线程超时冒充请求停止。成功缓存60秒、失败10秒；60m基础柱可复用给120m。同会话至多1个、进程至多2个图表任务，取数/计算在全局锁外；缓存随研究记录有界，不持久化、不占模型额度。完成前重新鉴权和核对重置代次、记录退休状态；重置、删除、到期和关闭清理缓存，迟到结果不回写。前端切周期/回日线/卸载会取消等待并丢弃过时响应；取数失败回到原日线，不重试研究。加载中的周期按钮显示省略号及可访问的忙状态；快照更新时立即刷新真实性警示，并取消旧周期取数。前端允许连续小时柱首尾相接，仍拒绝重叠、重复和倒序。

指标从 `indicators.py` 抽到只处理有序数值的 `_indicator_values.py` 内核，日线入口保留真实 DailyBar 类型、同股和日期递增校验，分钟柱不伪造日期。图表按原参数在所选周期重算全部10类指标；SMA20 周线代表20根周线，缺历史为空。抽取前的十类数值保存在固定黄金夹具中逐项回归。小时线醒目标明“分钟数据有延迟、非实时”，历史研究窗口取数不冒充原保存分钟快照。

分钟适配器与缓存仅由图表接口引用，不进入保存研究、证据、研判、价位或模型消息，也不改聊天重放快照。离线隔离测试比较调用前后的这些实际对象与模型消息，并改变分钟夹具确认研究不变。源码登记仅更新服务层指纹、保留历史，不改变路由规则、题库或标注。
