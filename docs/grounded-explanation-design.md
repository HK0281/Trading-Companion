# 受限指标解读：结构化论断、证据核对与安全回退

日期：2026-10-20（America/Los_Angeles）

2026-10-24增量：本文关系验证器仍负责检查论断及依赖；自然入口可用 `research-response-v1` 在同次最终调用中附带三段模型正文。新正文只保证结构与引用约束，不声称语义被程序验证。原“完全不接收模型自由文字”规则现仅适用于旧关系协议与程序事实报告；新网页展示边界见[自然语言答复设计](natural-research-response-design.md)。

## 1. 本步解决什么问题

此前 `safe_answer` 能安全展示程序事实，但模型解释仍只是调试草稿。仅检查“引用存在”也不够：模型可能引用真的SMA3，却把“高于”写成“低于”，或者把“高于”当成已经发生“上穿”。

本步不接收任意模型文字。模型从本轮工具结果中选择有限的指标关系，程序核对后，用固定中文模板呈现。模型负责选取要解释的关系，不负责指标计算、改写数字或生成预测。

```text
已确认请求 → 一次分析 → 当前完整事实 + 本轮短别名
                           ├─ safe_answer：独立事实摘要
                           └─ 模型提交JSON论断
                                  ↓
                    格式 / 请求 / 引用 / 依赖 / 关系核对
                           ├─ 全部通过：程序生成中文
                           └─ 任一失败：只展示事实摘要
```

这不是自由文本语义验证、行情真实性认证或收益预测能力；没有增加模型请求、行情请求或指标计算，没有自动修正、重试和换源。

## 2. 模型输出契约

```json
{
  "version": "indicator-explanation-v1",
  "request_id": "<本轮工具结果中的ID>",
  "instrument_id": "000001.SZ",
  "trade_date": "2026-09-25",
  "claims": [
    {"evidence_id": "<本轮关系事实的f编号>", "relation": "price_position", "value": "above"}
  ]
}
```

尖括号内容是说明，不是有效运行值。短编号必须来自本轮 `tables.relations`，不能硬编码，也不能用 `numeric_facts` 中的收盘价冒充关系。日期取实际最新交易日，不是请求截止日。

严格限制：全文不超过4000字符，1–8条不同引用；根对象及每条论断仅允许规定字段和字符串类型。拒绝额外文字、代码围栏、未知版本、重复JSON键、重复论断、数值/非有限数、缺字段和超限输入。不存在“先容忍格式错误再猜模型意思”的修复路径。

JSON契约说明位于第一次模型请求的system消息中；工具结果后不再插入system消息，保持已有消息配对协议。没有假定提供方支持某种新增严格输出API。

## 3. 程序检查什么

1. 先要求事实报告可用：结果必须匹配已确认请求的ID、股票、区间、来源及完整指标集合，仅允许等价重排。
2. 根对象的请求ID、股票和实际最新日须匹配；本轮别名映射须对应当前完整事实，不合并历史映射。
3. 引用必须指向真实、可用的 `RelationResult`，而非任意数字事实；关系名、值、参数、日期和关系事实必须一致。
4. 依赖须精确匹配关系类型的字段、顺序和日期；需要前值时，只能使用紧邻前一条记录，不能用更早值或当前值替代。
5. 检查依赖数值与相应行情/指标字段、单位、参数、可用状态及事实一致，再用已有原精度数值比较关系。**不重新取数，不重新计算SMA、RSI等指标。**
6. 所选论断全部通过才接受。任一错误会清空整段解读，保留独立事实报告；不会悄悄丢掉错误论断后声称整段通过。

请求ID用于关联，不是授权令牌。短别名如 `f12` 仅在当前映射中解释：若不同请求恰好都出现同一字面编号，程序无法判断模型心里想到的是哪个历史编号，只能验证它在当前请求中的含义。

本检查针对受信执行器返回的现有内部契约，不是任意Python对象的安全沙箱，也不独立重算或认证上游指标公式及行情真实性。

## 4. 支持的关系与措辞边界

| 范围 | 检查的关系 | 中文展示限制 |
| --- | --- | --- |
| SMA / EMA | 收盘价相对均线位置、均线数值变化、两点穿越 | 高于不等于上穿；不添加上涨概率 |
| MACD | DIF相对DEA位置/穿越、柱值变化 | 柱值增加或减少只指带符号数值，不笼统称动量增强/减弱 |
| RSI | 小于30、大于70或含边界的中间区间 | 精确30/70属于中间区间；阈值不是买卖信号 |
| BOLL | 相对三轨位置、等于边界、轨道重合 | 重合轨道单独处理，不漏掉相等情况 |
| ATR | 相对紧邻前记录的数值变化 | 仅波动尺度，不表示价格方向 |
| 量能 | 相对此前窗口均量倍率和1比较；当日量与此前均量比较 | 零分母倍率不可用，不妨碍有证据的成交量比较 |
| 均线对 | 左右命名均线位置及两点穿越 | 按实际执行请求的精确实例和顺序构造，不用子串猜测 |

所有比较使用原始精度；报告中的8位有效数字只作显示。极近阈值的值可能显示为30，却仍小于30，不能用显示文本反推关系。

模板中的指标名称、中文句子、限制及完整证据ID均由程序生成，不转发模型的自由文字。当前没有跨指标冲突总结、观察条件生成、新闻/基本面解释或历史状态证明。

## 5. 编排、状态与展示接口

`AgentTurnResult` 的输出职责分开：

| 字段 | 含义 |
| --- | --- |
| `safe_answer` | 独立程序事实报告；解释失败也可保留 |
| `explanation_validation` | `not_performed` / `accepted` / `rejected`，含固定检查范围、通过的论断、完整事实ID及程序中文 |
| `display_answer` | 默认展示文本：事实摘要＋通过检查的关系；失败则仅事实与固定回退说明 |
| `model_draft` | 原始模型输出，仅调试；不能默认展示或当生产脱敏日志 |
| `answer_validation` | 保持 `not_performed`，并以 `answer_validation_scope=free_text_semantics_not_performed` 明确不是任意自由文本校验 |

检查通过且全部请求字段可用时，整轮为 `completed/research_completed`；有缺项仍为 `limited/partial_research`。检查失败时为 `limited/explanation_rejected`；若同时存在缺项，主code仍为 `partial_research`，检查原因见独立字段及 `failure_code`。模型超时、拒绝、截断或再次提议工具，沿用 `limited/explanation_unavailable`，不尝试校验半段内容。

展示属性按当前请求、草稿和证据重新检查，不缓存一个可与后续替换数据混用的“已通过”结论。无研究结果时 `display_answer=None`，调用方展示原有澄清/失败消息。

预算不变：明确格式及股票选择续接最多2次模型/1次分析；自然语言初始请求最多3次模型/1次分析。通用对话、全轮token/时长预算和真实模型场景评估仍未完成。
