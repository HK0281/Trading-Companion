## 协议和使用边界

实现见 [research_intent_v2.py](../src/trading_companion/research_intent_v2.py)。新工具名 `interpret_research_intent_v2`，版本 `research-intent-v2.3`；声明和校验共用严格结构定义。额外/缺失字段、错误类型、非法枚举、多个调用及无出处片段仍失败。先处理nullable字段（协议允许空值的字段）的固定空值拼写，再验证结构；其他受限纠正在结构验证后进行，最后核对全部依据和程序边界。原始响应不改写。

`confidence=low`（模型自报理解需求的低把握）不评价行情能否预测或收益能否保证。通过同样严格校验后保留字段并记录 `low_confidence=true`。程序确认的否决冲突、身份/对象边界及已有具体澄清原因优先，最后才用缺对象或条件不明兜底；不能把conflict统一覆盖成conditions，也不能把reject改为可执行研究。字段或出处非法仍失败。第3步再接确认按钮，本批没有用户按钮或产品行为变化。

唯一可撤销的模型澄清是：本轮确有`explicit_subject`纠正，且成功绑定唯一对象，原因为subject。此时只撤销这一原因，其伴随的low不再重启同一澄清，但仍记录`low_confidence=true`。原本已给显式对象却仍报subject、身份歧义、要求冲突及其他原因都不适用。复用的旧纠正日志也不授予本轮纠正资格。

- 模型输出任务、操作、分析/方向/评级目标、是否要具体价位、对象出处、历史日期、未来期限、指标、领域和排除项。个股统一为 `stock_research`，技术面是范围。
- analysis用于历史/当前观察；outlook仅为不需价位的指数未来方向；decision用于个股未来方向/评级/买卖判断，以及股票、指数的条件价位情景。指数decision不授予个股评级或交易权限。个股带短/中/长线研究期限仍面向未来，否决计划只撤销价位。购买价值判断按产品约定同时请求价位，纯方向/只评级不自动增加价位；缺对象优先问对象，已有对象缺价位期限才问期限。
- 明确技术面、技术指标、具体指标（含均线）、日线/周线数据属于technical；仅走势/趋势/表现/波动不自动限定。基本面包含profile+financial；“最新”不等于news，价位公式依赖或否定ATR不增加technical。筛选PE/PB属于筛选条件。
- 目标、价位、严格范围需要原文依据，领域与排除项逐项带原文。模型不输出绑定后的证券代码、换算日期、来源、工具权限、公式参数或实际价格。
- new表示新研究、仅沿用对象继续研究、从保存名单选成员发起研究；update表示明确修改当前任务条件或续接有效待办。替换当前研究对象仍是update，但不继承旧对象日期/期限/指标/范围等条件；另起研究另一公司是new。有效pending下的期限回复及对象替换都是update，只有update能借待办目标/价位依据。refresh表示重算或重新核验已有研究，包括仅更新旧报告/计划数据；explain只解释已发布结论。要求冲突不抹掉用户原本目标。selection只放指代词/序号，不能用公司、资料或时间名充当选择。
- 程序核对目录身份、指数白名单、日期、期限和指标。明确否决撤销价位请求；模型同时肯定该请求时预计冲突澄清。严格范围不能悄悄增加 ATR（计算风险价位所需的波幅指标），缺依赖记录 `plan_blocked`，不授权扩充范围。
- `CheckedIntent.fields()`提供题库14字段；`outcome`是**预计动作**，不表示已研究或发布计划。知识/回顾的 `local` 预计动作不代表生成了答案，也不表示本次理解零调用。历史窗口、出处及阻断原因另作程序元数据。

期限区间使用完整表达式解析：N～M、N-M、N至M、N到M个月/周/天/交易日，以及相邻中文数字构成的范围。取中点，周按7天、月按30天、年按365天换算，再按既有短/中/长档归为10/40/120交易日；半天中点向上取整。区间必须为正数、顺序明确，上限不超过366天或交易日；没有整句特例。完整的未量化表达“近期、最近、后面、后续、以后、接下来、将来、未来、现在、目前、当前、近来、近日”表示期限未明确；只在请求价位时追问，不选短线。非法量化期限仍澄清，不吞掉数字。历史窗口不得充当未来期限。普通单一期限保留既有换算。

### 否决规则登记

规则版本为 `intent-v2-guards-v3`，只作用于独立候选新意图，不改变生产规则 `index-scenario-ui-v1`。沿用的否决词表 `_NEGATION` 为 `不要|不用|无需|不需要|排除|禁用|不看`，可接 `再|给|提供|计算|分析|研究` 和空白；目标包括计划/价位/目标价、风险、技术面、财务/财报、公司资料/背景、新闻/资讯、公告及协议中的指标名。它只能撤销权限或报告矛盾，不参与普通肯定研究任务或价位分类。完整表达式以源码为准，指纹随计划保存。

严格范围及指标完整性检查复用原有 `product_scope`。普通肯定研究意图仍由模型理解，不新增研究分类词表；本轮新增的本地保护例外见下节。提示词使用语义定义和通用表述，不照抄开发题整句。

### 唯一规范化实现及审计

所有受限纠正都在协议层的 `check_response()`，评估层无第二份算法，第3步正式入口应直接复用。每次记录kind/field/before/after/source（类型、字段、原值、新值及来源），失败题中已尝试的纠正也保留：

- nullable字段仅接受固定的空字符串、null、none、无拼写；非法操作枚举仍拒绝。未写出的普通隐含代词可降null，多对象不因降null而自动选一只。新增两种只降低对象声明的纠正：完全没有latest、任何待办或保存名单时，previous可降none并清selection；source=none时可清掉来自原句的selection。两者均不绑定对象、保留澄清，不删除无出处的虚构名称/序号。有记录但过期/失效的previous仍走原校验，不冒充“无记录”。
- 本句完全没有普通指代词（它/它们/这只/该股/这家公司/该公司等）、上一对象指代或序号指代，且只有完整、唯一、任务兼容的证券对象时，才将previous/none纠正为question。这项只纠正出处；其subject澄清撤销例外见上文，操作和价位不改。含指代词时不自动判断比较还是替换，即使模型selection为null也跳过这项纠正，交原输出及正常校验处理；可能多一次澄清，不能丢掉另一个对象。显式对象列表遗漏成员仍拒绝。
- outlook只在股票任务或未确认对象的clarify任务中规范为decision，记录`objective_outlook_non_index`；指数任务及已核实的指数对象不改。不补价位、目标依据或期限。
- task=clarify但已合法绑定唯一对象且原因不是subject时，恢复对象对应的股票/指数任务；澄清原因和low保留。恢复后执行同一套领域、严格范围、指标和日期检查，不能借恢复任务跳过指数不支持财报等边界。
- “基本面”已出现在profile/financial领域的原文依据中时，补齐二者；财报等具体领域不扩充，新增领域仍过排除检查。指标片段只有在其全部出现位置均被更长的已提交片段覆盖时才去重；存在独立位置就保留，不把不同参数合并。
- 指数使用同一白名单身份核对别名，而非任意跨度重叠；完整“大盘指数”及紧跟后续观察、短/中/长线、计划、止盈止损、价位或走势语境的“创业板”可解析。ETF/基金/期货/期权及“创业板股票/个股”不绑定其指数；歧义、混合对象、未支持指数和遗漏第二对象仍拒绝/澄清。旧通用知识探针不认识的新别名留在语义路径。
- 指数默认technical可以去冗余，但先检查不支持的公司/财务等领域、排除与严格范围；具体指标保留，不借清空字段掩盖越界。
- screening/update明确指向有效保存名单时，previous可规范none并记录program_screening（程序保存的筛选任务）；不绑定股票。名单时限、来源、模式和身份校验仍生效；其他字段的改写依据仍拒绝。评估名单条件是占位状态，不代表真实筛选编辑已验证。
- 历史日期检查仅屏蔽已核实未来目标依据中的“未来方向/走向/走势/趋势/表现/行情/前景”之“未来”二字，逐次记`future_objective_date_cue`。V2084原失败来自旧日期探针把“未来”当成未识别日期，与ATR无关；纯方向且不要价位不要求ATR。不会屏蔽整段目标依据；未提取的量化未来、若干天、今天数据、非法历史日期仍须澄清。normalize=false时保留原检查。

### 新增候选零理解调用保护

协议层的 `local_preflight()` 统一承载候选前置，正式入口尚未接入。每条结果记录规则出处，不按题号或gold免调用：

| 路径 | 原生产行为与本轮候选差异 |
| --- | --- |
| 命令、严格整句公司期限回复、既有指标概念/回顾/执行保护 | 复用既有谓词；期限回复有附加条件则走理解，不截断 |
| 通用知识（含V2147/V2148） | 复用原probe_general_knowledge/resolve_general_knowledge；0次独立理解，仍需知识检索、回答及引用校验 |
| 旧知识入口误收的买卖/方向判断（含V2048） | v2.3在通用知识前置中复用wants_decision，仅阻止抢答，不自行分配研究任务。交语义模型完整理解；每题最多增加1次理解，缺对象仍先追问对象 |
| 历史方向/评级选择式回顾（含V2025） | 新增完整问句保护；旧回顾谓词漏认。需启用记忆且有历史，新对象/研究附句不截成回顾 |
| 提交/执行/发出/撤销委托或订单（含V2143） | 新增拒绝保护；旧执行/注入谓词漏认。整轮拒绝，不截掉附加要求后执行 |
| 仅解释保存的结论/依据/证据支持（V2126–V2130） | 真实有效缓存+同对象+完整解释语法；旧分支有部分依据/为什么解释，但V2129证据支持问法为新增候选。新对象、日期、刷新、评级、价位、附加条件均不得进入；证据解释优先于泛回顾 |

解释保护要求真实 `SavedProductResearch` 及资料bundle（程序保存的研究资料）、已通过校验的回答、匹配的最近对象、15分钟时效、来源/模式和目录身份。没有缓存的布尔声明不授予解释权限。它只省理解调用，未生成解释答案或跳过证据检查。

已知误拒：委托保护可能把“撤销委托一般怎么操作”一类通用知识问法也整轮拒绝。#368同意本批保留；第3步向用户说明各路径调用次数变化时必须列出此代价，再决定是否收窄，不能把它当作已解决的知识路径。

调用次数变化清单还须列出v2.3知识前置收窄：普通指标定义、价值投资/短线概念问法仍可零理解；命中既有交易/方向判断谓词的问法先交模型，即使最终判为知识也可能多一次理解，知识回答调用另算。这是独立候选差异，正式入口未接入。

`understand()`是显式语义接口，最多一次模型尝试，无重试。复用受控模型、唯一系统消息、用量计数、取消和90秒截止检查，保留实际响应model和用量。非法输入、不可用目录在调用前拒绝；取消或过晚响应不返回可用意图。不修改会话、不读行情、不执行研究。

它**不是正式路由入口**。命令、历史、幂等重放、严格整句待办、确定性定义和拦截仍由原入口处理；不能先调用它再声称保留零调用。待办附带条件不能截掉后半句。本批沿用正式会话回顾、期限按钮和本地保护的现有回归，后续接入需另审并测量。

## previous绑定

`IntentContext`只接受程序会话、目录、时钟、日期和来源配置。历史问题帮助理解但不授予身份。上下文还说明最近发布、原期限、待办和可信名单状态，模型不能覆盖。

最近身份复用 `ResearchSession.latest_research` 和 `checked_subject`。失效、未来发布时间、来源/模式变化、目录身份改变、不同会话没有发布记录时不绑定，不回找旧缓存。指数和股票分开核对，ETF不当作指数。

15分钟是资料和条件复用时限，不是股票身份时限：899秒内同对象可继承期限；900秒起仍绑定合法股票，但不继承旧期限，需要价位且无新期限则询问。显式新对象不继承旧期限或证据。多个对象的“它”先选择，序号或完整复数只选同一次发布。

可信待办保持原创建及过期时间，绑定会话实际保存的对象；多待办冲突不猜。公司期限待办由价位门禁创建，不能只看旧 `wants_risk` 标记。有效待办的original_question只允许同任务的update引用objective_phrase/plan_phrase，记录program_pending出处；普通history不授予依据。换股票可续任务目标/价位意图，日期、期限、对象、指标、范围和排除仍来自本句；否决覆盖，不带旧对象条件。指数价位待办目标一致为decision。名单序号复用原有完整选择解析器，检查时限、来源对象、研究来源、开发模式、证券身份和展示顺序，失败不退回另一只旧股票。

v2.3将“上一只/上一个/刚才那只”作为最近一次发布的单对象指代，而非数字序号，记录`previous_single_reference`绑定结果。只能在同来源、同模式、身份有效的最近研究里绑定唯一对象；多只候选、失效身份或无记录仍澄清。它不改期限门禁，901秒旧研究仍丢弃原期限；不从更早历史找对象，也不借该规则从待办/名单猜一只。
