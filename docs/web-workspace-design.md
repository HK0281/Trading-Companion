## 1. 本轮解决的问题

此前只能在终端或 Swagger 提交请求。现在用户可以直接在网页输入中文问题，查看事实、关系和证据字段，处理股票澄清，以及查看历史、检查状态、请求取消、重置和结束会话。本轮没有新增研究工具、模型提供方或交易权限。

```text
React 展示组件
  → ResearchController：页面状态、内存凭据、未确认请求
  → createApi：固定 normal / dev 同源前缀、DTO 检查、固定错误
  → FastAPI → 两个隔离的 ResearchApiService → 原 Agent / 工具 / 事实检查
```

页面不会替 Agent 判断股票身份、计算指标或生成投资结论；也不直接连接模型供应商。

## 2. 安装、构建与运行

Web 运行使用前端编译产物。首次克隆、修改前端源码或构建发行包前，需要重新构建；升级双模式后也要重启 Python，使新路由与界面匹配。

准备 Node.js 22.12+（建议使用受支持的 LTS 版本）及 pnpm 11.25.0。普通 Windows Node 安装通常自带 npm，可用 `npm.cmd install --global pnpm@11.25.0` 安装 pnpm；不需要激活 Python 虚拟环境。项目根目录运行：

```powershell
pnpm.cmd --dir frontend install --frozen-lockfile
pnpm.cmd --dir frontend test
pnpm.cmd --dir frontend build
```

`pnpm-lock.yaml`锁定解析结果；安装脚本只显式允许 esbuild。没有自动执行的部署、供应商配置或模型调用。不要把密钥写进前端源码或 `VITE_*` 变量；前端构建内容对浏览器公开。

Python API/模型依赖尚未安装时先执行第一行；按[本地配置](local-environment.md)填写根目录 `.env`、准备有效真实目录后，日常只需启动命令：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[api,model,dev]"
.\.venv\Scripts\python.exe -X utf8 -B -m trading_companion.api_server
```

打开 <http://127.0.0.1:8765/>。同一进程仍提供 <http://127.0.0.1:8765/docs>。默认正常后端为 DeepSeek + 腾讯历史日线；启动只做本地检查，缺配置或目录不自动降级。Ctrl+C 停止服务。

没有开发服务器或第二个端口；修改 TSX/CSS 后重新 `build` 并刷新页面。刷新会丢失页面内存中的会话令牌，所以应在无在途请求时刷新。

### 正常与开发模式

页面默认正常模式，首次明确发送才创建会话并提交问题；页面载入、草稿和 health 检查不调用模型或行情。正常问题可能发送给 DeepSeek 并计费，密钥始终只在服务端读取。

Dev Mode 按钮把当前页切到服务端预配的 `fake + synthetic` 独立服务：`/dev-api/health` 与 `/dev-api/v1/sessions...`。正常服务仍用 `/health` 与 `/v1/sessions...`。切换不是让客户端自由配置来源，也不改变已存在会话的提供方。两个服务的令牌、研究状态、幂等记录、模型实例和预算相互隔离。

只允许空闲、无在途或响应不确定的请求时切换。旧会话清理失败保留原模式和内容；清理成功后即选择目标并清空聊天/草稿，再检查目标 health。目标失败仍留在目标断连状态，不恢复已删除聊天、不自动回退或重发；可手动重连或重新切模式。切换不会预先创建新会话，下一句明确发送才创建。页面刷新回正常模式，不能借刷新绕过不确定请求的恢复要求。`--demo` 则完全离线、不读 `.env`，没有可切回的正常后端。详见[模式设计](dev-mode-design.md)。

### 固定离线体验

正常启动后先点击 Dev Mode；没有真实配置、只想离线演示时也可用 `api_server --demo` 单独启动。

1. 直接在输入框输入问题；页面载入本身只读取 health，不创建会话或请求模型。
2. 输入“分析平安银行，2026-09-21 至 2026-09-25，只看SMA3和RSI2”，点击发送箭头或按 Enter。
3. 输入“这里的RSI为什么偏高”并发送；这次读保存结果，不重新取数。
4. 可穿插“解释一下MACD里的DIF和DEA”；定义回答不调用模型或行情。
5. 输入“把SMA3改成5日，其他不变”并发送；这会产生一次新的分析。
6. 输入“查看上次结果”；页面明确标注历史，不把它当作新研究成功。

首次发送自动建立会话并发送该问题；后续消息沿用同一会话。“新对话”结束并清空当前对话，回到可输入状态，直到下一次发送才创建新会话。当前只有一个内存会话，不支持切回旧聊天。Fake 是有限脚本，不是能回答任意问题的假语言模型；人工数据固定在2026-09-21至09-25。重置不重建脚本，也不返还额度。重跑整套演示点击“新对话”后再发送，不要在同一会话连续重复初始问题。

人工目录只有平安银行、中国平安、贵州茅台、中芯国际四条记录，人工日线仅包含平安银行五天；Dev Mode 不能分析任意股票。显式 `--provider deepseek --data synthetic` 仍是可能计费的真实模型配人工数据，不等于离线 Dev Mode。`--data` 可显式覆盖正常后端的启动来源，但不通过网页消息、URL参数或请求体配置。重试仍须用户明确触发并使用原服务的原请求编号；去掉前端许可门不等于供应商接入验收或授予下单权限。

React 用 `useSyncExternalStore`订阅不可变快照，组件不拥有模型逻辑。同步的操作门在等待HTTP之前置位，所以快速双击不会产生两次提交。TypeScript帮助发现源码里的接口错误；`fetch().json()`仍需运行时检查，包括返回的请求编号必须匹配当前问题。

前端产物输出到被Git忽略的 `src/trading_companion/web_assets/`，源码与锁文件进入Git。Python包配置包含编译后的HTML/JS/CSS；打包前先build。本轮实际检查了wheel中的这三类资源，不宣称整个项目已成为脱离源码目录的独立发行产品：原开发CSV/目录夹具仍有自身的项目路径约束。

## 4. 网络失败与取消的状态

| 情况 | 页面行为 |
| --- | --- |
| 收到匹配的公共响应 | 展示可读状态和答案，不附加内部诊断面板；再只读刷新额度。刷新额度失败不抹掉已收到的答案 |
| 断网、120秒浏览器等待超时、成功响应格式/编号错误、未知网关错误 | 保留原问题和编号，标记“响应未确认”，阻止新问题、重置、删除及模式切换 |
| 点击“重试原请求” | 只由用户触发，使用同一编号和同一问题；可能取回缓存，或执行先前尚未接纳的请求。重放不被当成新的问题，聊天不额外展示调用计数 |
| 409仍在执行 / 429并行容量满 | 不自动重试；保留原编号，允许手动检查或稍后重试 |
| 已知固定终止错误 | 展示固定说明，结束当前请求；不把服务端失败自动变成第二次模型调用 |
| 401/404会话失效 | 丢弃页面凭据，不重做失败问题；提示下次明确发送会开始新对话，原研究条件不保留 |
| 点击“请求取消” | 单独发送匹配编号的cancel；202不清除在途状态，不声称远程已停止或免费 |

浏览器超时只停止等待，不等于后端取消。状态检查只读取进程内状态；服务端空闲也不证明丢失的原请求没有执行，仍应用原编号取回答案。该机制依赖原API的进程内幂等记录，不是跨重启或分布式exactly-once。

创建会话的响应如果丢失，没有可恢复的令牌；不会自动重建或提交研究，输入框恢复原问题，由用户再次点击发送。原不可访问会话等待30分钟绝对有效期后的惰性清理。创建、首条消息和模式切换受同步操作门保护，避免快速双击创建多个会话或把旧模式结果写入新聊天；创建返回后仍检查会话生命周期和所选服务固定的模型／数据来源，不再检查已移除的前端发送许可。

## 5. 展示与安全边界

- 优先展示已校验的公共 `conversation` 自然语言正文，兼容旧紧凑视图；不读取调试草稿。React按文本渲染，不执行用户/模型HTML，不使用 `dangerouslySetInnerHTML`。
- 仅确实需要澄清时显示候选；旧回答的候选不可再次点击，历史也不展示选择按钮。点击仅填入代码，不自动执行。
- 展示已确认股票/日期、来源/人工标签和可读状态；图表、证据、证券背景与完整报告可按需展开。聊天不展示内部代码、本轮调用数、默认参数清单、工作流或引用诊断；舍入仅用于显示，不在前端重算关系或预测。
- 没有“本轮详情 / 参数与执行记录”附件，也没有回答后固定的 RSI、DIF/DEA 和调整指标追问按钮。追问直接在输入框输入，证据附件不是执行诊断面板。
- 历史有独立标记；聊天最多保留40条页面记录，不等于后端保存完整对话，也不会把整个页面记录重发给模型。
- 令牌不放进URL、localStorage、sessionStorage、Cookie或文件；仅保留在当前页内存，开发者工具仍可能检查到它。刷新/关闭不自动撤销服务端会话，原绝对TTL不续期。
- 所有请求同源、无Cookie；保留现有Host/Origin、16KiB、Bearer与no-store保护，不为了UI增加通配CORS。
- 根 health 的可选 `development_mode_available` 仅用于决定按钮可用性，不是服务端权限边界。开发路径仍校验自己的令牌、来源和额度，不能复用正常服务会话。
- HTML设置CSP：脚本、样式和连接只允许self，禁止内联/eval、第三方嵌入和外部base。不从CDN加载React、字体或图标。
- 后端只提供index和有限文件名的JS/CSS；拒绝目录逃逸、source map、TSX、Python和环境文件，不设置“任意路径返回HTML”的兜底。
- 键盘有焦点样式、控件标签和live状态；中文输入法合成期间不会因Ctrl+Enter误发，候选与示例都要再次确认发送。手机证据表内部横向滚动，不撑宽整页。

这不是用户登录系统或公网部署。前端按钮与TypeScript类型不能代替后端权限、额度或事实校验；移除发送许可卡不会移除这些后端保护。

## 7. 证券状态与交易日历背景增量

`App.tsx`在研究结果旁接入 `MarketContext`。数据来自可选 `result.market_context`，由 `marketContextData.ts`从unknown独立校验，不参与 `api.ts` 对核心响应的确认：坏背景不能导致重新请求、正文丢失或输入锁定。组件只渲染，不请求新API或调用模型。

页面显示分析日板块、ST／全天停牌、上市日期及自然日年龄，另显示开市／休市／未知日期和行情未匹配／冲突日期。卡片明确标记人工或本地未核实来源、有效期、发布时间、采集时间、非PIT、非交易规则；缺行情不等于停牌。历史由原保存背景生成，显示“已保存上下文 · 非新查询”，不刷新文件。非法／不可用背景只显示固定局部提示。

默认人工属性不是这些真实股票的市场事实；真实主数据／日历接入待做。114项独立卡片／校验测试加6项HTTP客户端／App集成通过，前端全量256项、Python1054项、构建与打包全通过。真实卡片浏览器验收未完成；不使用其他访问方式绕过前述浏览器策略。配置和时间语义详见[背景设计](market-context-design.md)。
