# 跨指标现状综合解读

## 1. 解决的问题与边界

事实报告回答“数值是多少”，单项关系回答“两个数谁更大”。本模块进一步按趋势、动量、波动和量能整理这些关系，明确已知、分歧与缺项。它不预测未来价格，不给收益概率、目标价、止盈止损或交易指令。

核心文件：[research_synthesis.py](../src/trading_companion/research_synthesis.py)。入口：

```python
build_research_synthesis(result, *, expected_request) -> ResearchSynthesis
```

输入必须是同一请求的 `MultiIndicatorResult` 和已经确认的 `MultiIndicatorRequest`。保存的研究可直接用保存的 `result/request` 重建摘要，不取新行情、不调用模型、不延长历史结果有效期；历史查看仍需由会话入口标明保存时间与“不是最新行情”。

## 2. 数据流

```text
确认请求 + 已有计算结果
  -> 既有 build_research_report 请求/最新证据检查
  -> 检查本模块实际使用的最新、紧邻前一条数值及 fact 依赖
  -> 四维度有限关系
  -> 趋势/动量参考相容性 + 条件化观察 + 限制
```

不读取 `result.relations` 的结论标签，也不采用模型文本。即使某个旧标签被篡改为“高于”，本模块仍直接比较已核对的数值。BOLL 轨道宽度只是已算上下轨的差，ATR 变化只是两条已有记录的比较；没有重新计算任何指标或补历史。

### 证据检查范围

每个实际使用的数值需要匹配完整股票代码、请求编号、指标参数、算法版本、字段、单位、业务日期、所需/已有记录数、可用状态及对应 `Fact`。依赖只允许实际最新日和紧邻前一条记录。公开引用使用程序生成的规范 fact ID，不能塞入任意文本。

这验证的是请求绑定和数值依赖契约，不是重新证明指标计算、数据供应商真实性或全部历史数值。同步篡改数值及其完整证据并非本模块能全面识别的情形；不承诺密码学防篡改或投资质量。

## 3. 明确且有限的规则

| 维度 | 允许描述 | 不允许推断 |
| --- | --- | --- |
| 趋势参考 | 收盘价相对各 SMA/EMA 的位置、均线相对紧邻前一条记录的变化 | 均线就是固定支撑、未来趋势或买卖信号 |
| 动量参考 | MACD 的 DIF/DEA 位置、柱值变化；RSI 相对50和30/70参考区间 | 柱值增加就会上涨、RSI超过阈值就会反转 |
| 波动尺度 | BOLL 上下轨重合与否、轨道宽度变化、ATR尺度及变化 | 波动扩大意味着上涨或下跌 |
| 量能参考 | 量比相对1；严格此前均量为零时量比未定义 | 放量独立确认上涨、零基线等于0倍或无限倍 |

RSI 的50是本项目显式选择的参考中线，不是交易胜率。RSI=30/70属于含边界的30至70区间；RSI=50为中性边界。零MACD、零ATR、零当日成交量不会因为数值为0而被当作缺失。

同族多个参数逐实例展示，使用关系的集合而非多数计票：多个短均线不能“投票压过”一条相反的长均线。等于参考值是中性，不自动算成与上侧/下侧相反。

跨维度只比较均线价格位置和 MACD/RSI 的参考位置；波动与量能不参加价格方向表决。相同上侧/下侧只表述“本次参考关系相容”，不称为走势确认。缺少 MACD 或 RSI、缺历史或其他必要数值时，相应完整性保持受限，不把未知当作支持。

## 4. 返回契约与失败隔离

`ResearchSynthesis` 是不可变 dataclass，提供 `status/code/text` 与 `.to_dict()`。DTO版本为 `research-synthesis-v1`，来源固定 `application`，验证范围固定：

```text
request_local_numeric_reference_comparisons_not_predictions
```

主要结构：

- `dimensions`：固定四维度，每项含状态、有限状态描述、观测及缺项。
- `observations[].dependencies`：支持该有限结论的原数值 fact ID，不伪造综合“投资事实”。
- `cross_dimension`：相容、冲突、不完整或中性边界，并列出实际使用的依赖。
- `conditions`：若后续参考关系改变，应如何用新记录重新核对；不是预测或自动触发器。
- `limitations/evidence_ids`：保留复权、初始化、缺值、实际最新日期及非PIT限制。

成功状态为 `complete/limited`，只表达本摘要的字段完整性，不表示预测可靠性。冲突也可以是证据完整的结果。错误分为：

| 状态/代码 | 含义 |
| --- | --- |
| `blocked / synthesis_evidence_mismatch` | 请求、数据结构或实际使用的数值证据不一致；不展示部分结论 |
| `unavailable / synthesis_data_unavailable` | 无有效行情，不推断缺失原因 |
| `unavailable / synthesis_payload_limit` | 整份UTF-8 JSON超128KiB，不截断展示 |

异常不输出原始异常、源路径或模型草稿。综合解读不可用时，调用方可以保留已经独立通过检查的事实报告，不应把事实报告也宣称为模型验证结果。

## 5. 测试与后续扩展

测试入口：

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m unittest discover -s tests -p test_research_synthesis.py
```

覆盖真实人工CSV的7类指标、上下侧与矛盾、同族多实例不计票、零值与阈值边界、缺历史、零均量、错请求/证据/前一条记录、关系标签污染、计算错误、深隔离和无取数/模型调用。

后续如需改变参考规则，需增加明确规则和边界测试，而不是让模型自由生成方向分数。真实行情覆盖、模型语言质量、历史PIT和策略收益评估仍是相互独立的工作。
