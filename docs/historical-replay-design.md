# 历史回放与本地归档读取

本模块提供一个可复核的基础策略比较，用于检查数据、时序和评估代码。实现位于 `historical_replay.py`，自然语言公司研究通过 `product_research.py` 接入，不另外请求行情或模型。

## 方法与数据流

只实现一个明确方法：前一条已完成日线的收盘价高于同日 SMA 时，在下一条记录开盘采用多头敞口，否则持有现金。收益区间使用该开盘至下一条开盘，末条开盘结束，并扣除最终退出成本。基准是在完全相同起止开盘之间持续持有。不能使用信号日收盘价成交，也不能先看当天收盘再选择当天开盘的仓位。

默认 SMA20、单次敞口切换成本 5 基点；支持明确指定单个 SMA 和成本，例如“回测平安银行 SMA7，交易成本 0.1%”。不搜索最优参数，不把 RSI 或多条均线请求悄悄换成另一个策略。不支持的条件保留技术分析结果并说明没有执行回放。

输出净收益、同期持有收益、相对差值、两条曲线最大回撤、敞口切换次数及逐期时序。完整路径留在程序结果或可选归档中，模型只接收有界的方法、区间与指标证据，并受原来的数值和引用检查。

这是标准化敞口收益比较，不模拟实际订单、手数、资金账户、涨跌停、流动性、跳空成交或准确券商费率。数据复权、人工真实性与原快照一致；不复权价格的公司行动可能造成跳变。没有年度化、夏普率、胜率承诺或样本外有效性结论。

## 使用方法

正常网页可询问“回测平安银行 SMA20，和同期持有比较收益与回撤”。使用同轮已经校验的日线，保持单次读取；原有股票、日期、来源和整轮预算继续生效。当前只覆盖最多366个自然日的请求，不自动扩大历史。

启用服务端 `--snapshot-db` 后，归档也保存完整回放路径，保存前从原快照重新计算核对。已保存的归档可以离线查看和回放：

```powershell
.\.venv\Scripts\python.exe -m trading_companion.replay_cli --db .\data\research_snapshots.sqlite3 list
.\.venv\Scripts\python.exe -m trading_companion.replay_cli --db .\data\research_snapshots.sqlite3 show <snapshot_id>
.\.venv\Scripts\python.exe -m trading_companion.replay_cli --db .\data\research_snapshots.sqlite3 replay <snapshot_id> --stock 000001.SZ --window 20 --cost-bps 5
```

`--known-at` 使用带时区时间，限定本地实际观察与原采集时间；不能把今天首次取得的旧行情当作过去已经存下的数据。命令仅读取已有文件，不请求行情和模型，也不自动创建一个不存在的数据库。`show` 输出公共证据，不包含聊天或原始模型草稿。

## 验证重点

独立手算收益、相同基准区间、下一开盘时序、未来记录不改变已计算前缀、成本与最终退出、路径回撤、股票/日期绑定、归档完整重算及自然语言单次行情读取。真实市场的成交可行性和历史修订版本不由这些测试证明。
