# EMA计算：本轮小设计

日期：2026-10-13

## 范围

只新增纯计算函数与带股票/日期的结果点，不联网、不调用模型、不修改原SMA、分析结果结构或行情CLI。EMA是未来分析工具的底层能力，还不是Agent。没有新增依赖。

## 输入与输出

- `ema_close(bars, window)`：输入同一股票、日期严格递增的`DailyBar`序列和正整数周期；输出等长的`float | None`列表。
- `ema_close_points(bars, window)`：相同计算，输出`EmaPoint`，包含股票、日期、周期和值，避免脱离日期解释指标。
- 空输入返回空列表；不足周期时全部为`None`。非法周期（含布尔值）、混合股票、重复/逆序日期和非`DailyBar`项抛出`ValueError`，即使历史不足也校验。
- 周期数的是已有日线记录，不是自然日；日期间断不补零，不复制收盘。函数不负责截止日筛选，调用方先用`bars_as_of_close`截取。
- 计算层与现有SMA一样接受正整数。PRD中建议的1–120产品限制留给之后的请求/工具层，不在这一轮改旧接口。

## 固定计算口径

1. 前`window - 1`项不可用。
2. 第`window`项是前`window`条收盘价的算术平均，不用首条收盘直接初始化。
3. 后续使用`alpha = 2 / (window + 1)`，递推`EMA = alpha × close + (1 − alpha) × previous_EMA`。
4. 代码用等价式`previous_EMA + alpha × (close − previous_EMA)`递推；种子平均值逐步更新，避免有限大数先求和而溢出。周期1直接返回当条收盘价，避免相减抵消导致错误。
5. 计算过程不舍入，测试正常价格时用绝对误差`1e-10`对照独立Decimal公式；展示格式化留给上层。

人工示例：收盘`10、12、14、20、18、16`，周期3；结果`None、None、12、16、17、16.5`。这是测试数据，不是真实报价。

每条记录只访问当前收盘价与此前状态，时间复杂度O(m)。修改/追加未来记录不得改变已有日期的结果。更改计算起始位置可能改变EMA，不等同于使用未来数据。

后续MACD步骤提取了内部数值EMA：`ema_close`保留原签名、校验和种子口径，先提取经验证的收盘列表，再调用共享内核。数值内核不计返回列表时额外状态O(1)，包含收盘列表的日线包装层空间为O(m)。这是为了清晰复用输入而接受的中间数组开销，不宣称整个包装函数仍是O(1)额外空间。
