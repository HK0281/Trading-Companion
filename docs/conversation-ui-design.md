# 对话式研究界面

日期：2026-10-24。状态：已实现，替代早期测试工作台的默认展示。

## 本轮解决的问题

旧页面直接展示 `display_answer`：事实报告、关系解释、四维综合和多轮限制说明被拼在一起。仅调整字体不能解决信息重复，因此本轮同时调整展示协议和交互布局，不修改研究计算或新增模型调用。

默认阅读顺序：简短标题 → 最新关键读数 → 已核对的观察。K 线、证据、证券背景、完整报告和执行记录分别折叠。重复的通用免责声明不再占据主界面；人工行情、历史结果、缺失读数、模型解读失败等影响理解的信息仍直接可见。

## 数据与组件如何协作

```text
Agent 的核验结果 / 已保存的结果
  → public_turn：保留原 answer、report、chart 和状态
  → answer_presentation：研究 / 知识 / 追问的可选紧凑视图
  → 前端 parsePresentation：结构、数量、报告编号、股票、日期绑定
  → ResponseContent：读数卡片、观察与定义
  → App：消息列表、输入框、折叠附件和会话控制
```

- `src/trading_companion/answer_presentation.py` 只使用应用已核对的对象。简短句子来自已知关系枚举与固定模板，不用字符串替换删除任意模型文本，不把参考位置包装成收益预测。
- `research_followup.py` 保留已接受的定义主题和核对关系。追问视图只展示相关指标，标明“基于已保存结果 · 未重新取数”；历史概览必须匹配原快照。
- `frontend/src/presentation.ts` 把新视图当作可选数据。坏结构或错请求编号只让卡片降级，不丢掉已确认的答案，也不触发模型重试。研究读数仍来自原始 `report.fields`，显示舍入不改变计算精度。
- `frontend/src/ResponseContent.tsx` 分开渲染关键读数、观察、知识解释和证据表。超过六项读数可以本地展开；缺失值保留为“—”，不补零。
- `frontend/src/App.tsx` / `styles.css` 提供固定页头与输入区、独立滚动的消息区、会话目录和手机导航。自动滚动只作用于消息区，从最新回答顶部开始；用户上翻时不强制拉回。
- `frontend/src/controller.ts` 沿用原请求、取消、幂等重放和会话状态机；新增明确的通知级别，让实际错误始终可见，不通过错误文案关键词猜测是否显示。

新视图有异常时返回 `null`；旧客户端仍可读取原答案，新客户端也能展示没有新视图的旧服务响应。界面始终用 React 文本节点渲染外部内容，不执行 HTML。

## 使用变化

- 桌面左侧为当前会话目录，不是假装支持持久化的多会话列表。
- 打开页面即可输入，首次发送自动建立会话；不再要求点击“开始会话”。左侧“新对话”结束当前会话并清空页面，下一条发送时再创建。手机点击左上角展开导航，发送不依赖侧栏。
- Enter 发送，Shift + Enter 换行；继续支持 Ctrl/Cmd + Enter。中文输入法组合输入和 keyCode 229 不触发发送。
- 点击示例或澄清候选只填入输入框，不自动提交。
- 本机服务设置中查看配额规则、连接诊断、接口文档，检查状态或结束会话。
- DeepSeek 首次发送在输入框旁显示“允许并发送”，无需寻找侧栏开关；取消或修改草稿不会提交，确认后本次对话继续复用许可。设置仍可撤销许可，重试原请求也不会绕过确认。来源仍由启动命令固定，未增加模型、行情、存储或下单权限。

首次创建失败会显示错误并恢复原草稿，不自动重试；创建过程显示进度并阻止重复发送。初次检查连接期间仍可写草稿，断连时输入框旁提供重新连接。点击“新对话”不预先创建空会话；删除旧会话失败时保留原聊天和草稿，旧会话已过期则可直接回到空白对话。存在未确认的原请求时仍禁止另开会话或换编号重发。

## 构建与查看

当前工作区已构建。现有 Python 进程需停止后用原命令重新启动，再刷新网页，才能同时使用新接口字段和新界面。仅刷新旧后端会获得兼容降级的原文字回答。

从 GitHub 拉取后，在项目根目录运行：

```powershell
pnpm.cmd --dir frontend install --frozen-lockfile
pnpm.cmd --dir frontend build
.\.venv\Scripts\python.exe -m trading_companion.api_server --demo --port 8765
```

打开 `http://127.0.0.1:8765/`。离线顺序为“个股研究 → 追问 RSI → 调整指标”，指标知识可穿插。真实模式沿用[本地配置与启动](local-environment.md)，密钥不进入前端。
