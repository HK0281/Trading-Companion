## 正文标注恢复与引用清理

`answer_claim_recovery.py`在分句和定位数字片段之前，仅恢复正文中完整、严格合法的数字标注数组：以标注的text替换数组，将标注移入该块numbers。仍受1800字符、80个标注限制；重复键、非法常量、混合或残缺项、嵌套歧义不恢复，原文硬性拒绝内容不能被恢复掩盖。

恢复后仍核对证券归属、单位、数值、重叠及计划用途。MA20参数或“顶背离”等没有实际数据数字的标注可忽略；同text的重复标注全部合法才接受。普通不存在field可忽略；已有字段的值矛盾不能换字段。普通不存在、格式错误或无数字的ref可按实际送模同股证据重新匹配，原容差和唯一候选要求不变。已解析跨股、已解析值错、派生结构错和计划引用不降级。提示词要求text只写可读正文，numbers是同级字段。

提示词仍要求ref原样复制已提供编号，不添加前缀、不合并编号，text不放编号或JSON。普通“L:E49”视作无效标注后独立匹配，不推断E49或L49；计划数字使用它仍拒绝。不存在的标准L编号不降级。止损、止盈、入场/退出价、目标价及上下观察位要求匹配程序计划角色和来源，不能借相同收盘值绕过；同分句并列的历史低点仍按普通数字检查。

独立的E/L引用编号先核对存在与同股，再从正文清理；不把编号当数据。清理保留分句和位置，纯引用括号消失，只剩标点或空白的句子删除并计入删句。金额、证券代码和其他数据数字仍逐一核对。

`inline_binding_recoveries`统计已完成的块内数组迁移次数，不表示迁移后的数字已经通过。只在发生时增加公开质量字段，版本化运行记录保留已知零值，两套评估读取并汇总。原有整份JSON恢复计数含义不变。新增检查模块纳入两套评估的实现摘要。

## 指标参数与RSI关系

`answer_technical_validation.py`从确认计划、已校验日线及完整周线事实构造本地核对资料，不发送额外资料给模型，不写入公开保存协议。仅本轮领域内的指标可确认，未启用技术面的默认指标不因留在计划字段中而生效。

默认组合没有显式指定指标时，已有价格背景可能提供MA20、MA60。重新计算并核对这些背景记录的身份、股票、日期、原值、单位和标签后，只有实际送模的记录才能补充对应日线`sma(window=20/60)`许可；参数集合在检查时还会按当前证据重新筛选。裁剪后不能继续许可，严格“只看SMA3”不补背景均线，日线背景也不能代替周线证据。

SMA3、SMA(3)、RSI(14)、MACD(12,26,9)以及3日均线、14日RSI等前置参数必须与确认实例一致。参数先于一般日期/时段遮蔽核对，避免把“6日RSI”的6当作时段跳过。未确认的RSI6、错误MACD信号参数、残缺或多余参数直接拒绝，不能借用恰好相同的价格数字。显式周线还要求该周期的可用事实。真实读数仍核对原始值，index_points使用独立数值单位，不冒充价格。

“MA60（28.60元）”的括号读数和“ATR（1.5倍）”的计划倍数有明确单位，按普通数据检查，不当作指标窗口，也不跳过数字。“SMA(3)(29.7)”等额外无单位参数仍拒绝；“60日均线28.60元”也先核对窗口60，再核对价格。

“日线与最近完整周线均在EMA20上方”等有限的跨周期均线表达，必须匹配已重新计算、实际送模的同参数日周方向记录，且上方/下方与记录方向一致；条件表达、错参数、反向、错股、旧日或被裁掉的记录均拒绝。该关系记录只证明方向，不能替代单独的周线读数或RSI证据。

RSI（相对强弱指标）的30/50/70在核实关系后遮蔽，也允许不声称当前状态的常用参考阈值介绍。支持高于/低于、区间内、超买/超卖及中线/中轴。关系可使用本轮已验证、同股同参数同周期最新RSI，即使该值被送模预算裁掉；本地资料记录原事实身份，诊断标记local_computed_rsi，不伪造悬空E编号。普通数字候选范围不扩张。真缺值、旧日、跨股或错参数仍拒绝。裸RSI要求所选周期只有一个可用实例。

未明示周期先按日线完整核对，失败可用同参数最近完整周线；明确日线/周线和周参数不可互救。同一指标提及的读数及所有关系必须使用一个周期，不拼接日线读数和周线关系。SMA(5)63.102元、ATR 24.4380元等紧跟读数不当作额外参数，仍检查真实值。

低于/高于为严格比较，超卖小于30、超买大于70；区间内包含两端。实际42时低于50且在30至70内成立，实际45时低于30不成立；多项关系逐项核对。反向、否定、区间外、模糊靠拢和未来条件继续严格拒绝。关系检查先于普通数字匹配，其他价格、百分比等仍全部核对。

RSI条件和否定限制收窄到所在分句：前一分句“趋势可能反复”不污染后一分句；“若RSI低于30”“RSI不低于30”仍不当作无条件关系。实际45低于30必须失败，“仅供参考”不能洗掉假关系。

## 分句保留与计量v2

仅普通数字匹配错误可删掉错误独立分句，保留其他通过部分并整体复核。括号内逗号、千位逗号不切分；全角文本使用原NFKC（统一字符形态）定位。条件、否定、因果或对比依赖、只剩数字/连接词时整句删除。计划、跨股、假技术关系等不救援。数字计数只记初次检查，复查不重复计数；引用汇总实际保留片段的合法数字来源。

`numeric_validation_version=source-bindings-v2`、`sentence_count_version=sentence-counts-v2`。整句消失才计deleted_sentences，部分保留计partially_retained_sentences；同时公开generated_clauses、retained_clauses、deleted_clauses和分句删除率。忽略非数字标注、忽略字段、无效引用回退成功/失败、本地RSI及参考介绍各自计数。去重删除仍单列，不当作普通数字分句删除。

**删句统计由v1变为v2，不能直接比较历史17.5%、26.9%和当前整句率。** 两套报告同时显示整句率、分句率、部分保留数，旧字段缺失保留未知。117轮差异单独封存于[新覆盖层](answer-validation-routing-deltas.md)，历史v1～v6和三个观察器不变。

可复用回放入口为`scripts/replay_answer_validation.py`，输入诊断及对应正式报告，默认旧规则b5d77eb，以独立源码副本比较相同草稿。输入摘要、逐字段原句/保留句/拒绝位置、逐稿与首稿/修正稿统计只写`.agentbus/tmp/`。无法证明同轮公开事实对应关系的项目列replay_context_unavailable；不从被测正文推导参数或补取行情，不等同真实重跑删句率或完整评级形成率。

## 日期和指标参数

| 原文 | 日期 | 指标 |
| --- | --- | --- |
| 最近20天RSI6 | 最近20个自然日 | RSI6 |
| 近60日SMA3 | 最近60个自然日 | SMA3 |
| 近20日RSI | 最近20个自然日 | 默认RSI14 |
| 近20日均线 | 最近20个自然日 | 原默认SMA20、SMA60组合 |
| 20日RSI | 原日期默认值 | RSI20 |
| 20日均线 | 原日期默认值 | SMA20 |

“近/最近/过去”决定相对日数归日期，指标名后的显式数字或括号决定参数。提取前遮蔽相对日区间但保留位置，旧结构化研究与产品计划共用该政策。模型吞入日期时，仅纠正与原文唯一指标重叠、受该日期边界影响的短语；不补原文外指标、不忽略其他未提取指标。截止日、包含端点、自然日换算和不支持日期的澄清规则不变。
