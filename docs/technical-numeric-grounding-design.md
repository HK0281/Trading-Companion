本批承接任务 #226、方案 #227 与批准 #228。修复误删时继续使用原数字容差、评级和价位公式；不增加模型调用、行情请求或领域权限。

## 正文标注恢复与引用清理

`answer_claim_recovery.py`在分句和定位数字片段之前，仅恢复正文中完整、严格合法的数字标注数组：以标注的text替换数组，将标注移入该块numbers。仍受1800字符、80个标注限制；重复键、非法常量、混合或残缺项、嵌套歧义不恢复，原文硬性拒绝内容不能被恢复掩盖。

恢复后，来源存在、证券归属、字段、单位、数值、绑定唯一性、重叠及计划用途继续走原完整检查；坏标注不能变成无标注匹配。提示词要求text只写可读正文，numbers是同级字段。

独立的E/L引用编号先核对存在与同股，再从正文清理；不把编号当数据。清理保留分句和位置，纯引用括号消失，只剩标点或空白的句子删除并计入删句。金额、证券代码和其他数据数字仍逐一核对。

`inline_binding_recoveries`统计已完成的块内数组迁移次数，不表示迁移后的数字已经通过。只在发生时增加公开质量字段，版本化运行记录保留已知零值，两套评估读取并汇总。原有整份JSON恢复计数含义不变。新增检查模块纳入两套评估的实现摘要。

## 指标参数与RSI关系

`answer_technical_validation.py`从确认计划、已校验日线及完整周线事实构造本地核对资料，不发送额外资料给模型，不写入公开保存协议。仅本轮领域内的指标可确认，未启用技术面的默认指标不因留在计划字段中而生效。

默认组合没有显式指定指标时，已有价格背景可能提供MA20、MA60。重新计算并核对这些背景记录的身份、股票、日期、原值、单位和标签后，只有实际送模的记录才能补充对应日线`sma(window=20/60)`许可；参数集合在检查时还会按当前证据重新筛选。裁剪后不能继续许可，严格“只看SMA3”不补背景均线，日线背景也不能代替周线证据。

SMA3、SMA(3)、RSI(14)、MACD(12,26,9)以及3日均线、14日RSI等前置参数必须与确认实例一致。参数先于一般日期/时段遮蔽核对，避免把“6日RSI”的6当作时段跳过。未确认的RSI6、错误MACD信号参数、残缺或多余参数直接拒绝，不能借用恰好相同的价格数字。显式周线还要求该周期的可用事实。真实读数仍核对原始值，index_points使用独立数值单位，不冒充价格。

“MA60（28.60元）”的括号读数和“ATR（1.5倍）”的计划倍数有明确单位，按普通数据检查，不当作指标窗口，也不跳过数字。“SMA(3)(29.7)”等额外无单位参数仍拒绝；“60日均线28.60元”也先核对窗口60，再核对价格。

“日线与最近完整周线均在EMA20上方”等有限的跨周期均线表达，必须匹配已重新计算、实际送模的同参数日周方向记录，且上方/下方与记录方向一致；条件表达、错参数、反向、错股、旧日或被裁掉的记录均拒绝。该关系记录只证明方向，不能替代单独的周线读数或RSI证据。

RSI的30/50/70只在明确关系成立后跳过常量数字。支持高于/低于（大于/小于/超过）、区间内、超买/超卖，以及“中线”“中轴”等后缀。必须使用送入本轮检查的同股、同参数、同周期最新数值，并记录实际引用。缺值、被裁掉的证据、旧日、跨股、错参数或周期歧义均不能通过。裸RSI只有唯一实例和周期时可用；明确日线/周线可消除周期歧义。

低于/高于为严格比较，超卖小于30、超买大于70；区间内包含两端。实际42时低于50且在30至70内成立，实际45时低于30不成立；多项关系逐项核对。反向、否定、区间外、模糊靠拢和未来条件继续严格拒绝。关系检查先于普通数字匹配，其他价格、百分比等仍全部核对。

RSI提及前的前文若含“可能”“未”等词，仍保守拒绝关系。本批按审核#230保留该取舍，不扩大可接受语法；是否收窄到同一子句，待真实评估定位后另批处理。

## 日期和指标参数

| 原文 | 日期 | 指标 |
| --- | --- | --- |
| 最近20天RSI6 | 最近20个自然日 | RSI6 |
| 近60日SMA3 | 最近60个自然日 | SMA3 |
| 近20日RSI | 最近20个自然日 | 默认RSI14 |
| 近20日均线 | 最近20个自然日 | 原默认SMA20、SMA60组合 |
| 20日RSI | 原日期默认值 | RSI20 |
| 20日均线 | 原日期默认值 | SMA20 |

“近/最近/过去”决定相对日数归日期，指标名后的显式数字或括号决定参数。提取前遮蔽相对日区间但保留位置，旧结构化研究与产品计划共用该政策。模型吞入日期时，仅纠正与原文唯一指标重叠、受该日期边界影响的短语；不补原文外指标、不忽略其他未提取指标。截止日、包含端点、自然日换算和不支持日期的澄清规则不变。
