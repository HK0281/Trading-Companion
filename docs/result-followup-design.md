## 1. 这一轮交付什么

把此前的“研究一次、修改一项指标”扩展成一个可连续使用的功能块：

1. 研究取得通过事实完整性检查的结果后，在当前会话保留一份快照。
2. 回答“这里的RSI为什么偏高”“这里SMA3和SMA5的交叉关系”等有限追问，不重新取数。
3. 本地解释七类指标及DIF、DEA、MACD柱值，无需先研究股票。
4. 通过“查看上次结果”或终端 `/last` 显式查看最近成功结果。
5. 与原身份澄清、指标修改、重置和调用额度共用同一个终端会话。

不保存完整聊天，不增加数据库、RAG、向量检索或新的模型供应商。知识是项目维护的小型定义集，不是通用金融知识问答；追问是受控事实展示，不是任意因果解释或走势预测。

## 2. 三种状态为什么分开

| 内存状态 | 保存什么 | 不代表什么 |
| --- | --- | --- |
| `pending` | 尚待选择的股票候选、已校验日期及指标 | 已确定股票或已成功研究 |
| `confirmed` | 最近可信研究的条件与身份，供明确指标替换 | 本轮新查询已经成功 |
| `_last_result` + `_result_current` | 最近成功结果的独立快照，以及是否仍可作为当前结果 | 实时行情、永久授权或完整聊天历史 |

`SavedResearch.checked()`先深复制结果，再调用原 `build_research_report()`检查请求、字段和证据，并要求有可解释事实。完整结果与部分可用结果都能保存；模型解读失败不妨碍保存可信事实。无数据、全部不可解释或完整性失败不保存。

Python的 `frozen=True` 只禁止给dataclass字段重新赋值，不会冻结内部字典。保存、读取结果和返回快照时分别隔离可变内容，避免调用方修改原结果或返回对象后污染会话。私有字段仍是进程内代码约定，不是抵御恶意Python代码的安全沙箱。

结果只保留最近一份，15分钟后失效，以研究轮传入的可信起始时刻计时；追问和查看不会续期。这是会话复用期限，不是行情实时性承诺，也不是整轮硬超时。时间倒退同样失效。

## 3. 当前结果与历史结果

```text
成功研究A → 保存A，current=true
开始执行新研究B → 清旧修改基准，保留A但current=false
  ├─ B取得可信事实 → 用B替换A，current=true
  └─ B失败 → A只能显式历史查看，不能回答“这里的RSI”
```

- “开始执行”指请求已准备好进入原研究链路；本地无效修改或尚未完成身份澄清，不冒称已启动新研究。
- B失败后，“查看上次结果”可看A，但会显示旧股票、原日期、实际最新交易日、来源、保存时刻和历史标签。
- 查看A不恢复已消费的指标修改基准，也不把A重新标成当前结果。接着隐式追问仍得到 `no_current_result`。
- `/reset`、明确“新问题：”及原重置命令清除全部状态，包括旧结果；不是保留历史的入口。
- 有待选股票时，精确知识问题和显式历史查看不消耗待选请求；其他含糊追问仍先完成股票选择。

每次复用前重新核查15分钟期限、当前目录时效、原身份是否存在或更名、来源及开发CSV配置，以及事实完整性。失败清除失效结果；不会自动刷新目录或重取行情。会话导出仅附结果范围和时间等元数据，不附完整结果、CSV路径、聊天或模型草稿；导出仍不是生产审计日志方案。

## 4. 追问的数据流

```text
用户追问 → 检查会话快照与范围
  → 最多一次模型调用：仅判断回答类型、复制指标提及
  → 程序检查调用与指标 → 从快照选字段
  → 必要时重新核对已保存关系的证据与数值依赖
  → 程序渲染答案；不调用行情工具
```

模型工具 `interpret_saved_research_question` 仅接受：

- `request_id`：必须属于程序提供的这份快照；ID用于关联，不是认证凭据。
- `action`：`facts`、`explain`、`relations`、`clarify`或`unsupported`。
- `topic_mentions`：最多12项，必须复制用户原文，不能自行替换股票、参数或证据。

模型只收到当前问题及保存请求的股票、日期、指标范围，不收到完整结果、完整聊天或旧草稿。它选择回答类型，不生成最终数值或展示文字。仅接受一个正确工具调用；多调用、错误工具、额外字段、错ID和捏造/遗漏已识别指标都会阻断，不自动修复或重试。

本地识别到其他目录股票、新日期、实时/最新要求、改来源、新闻原因、预测或交易要求时先阻断。对KDJ、OBV等明确列出的未支持指标也先阻断，避免模型只提取RSI后静默丢弃另一个要求。这些规则及原文覆盖检查有限，不能证明任意中文意图都理解正确。

字段只从原研究计算过的实例中选择。原结果同时有SMA3和SMA5时，只说“SMA”须澄清；明确两者则能显示对应的均线对关系。未计算MACD或RSI14不会补算；缺历史和未定义保持原状态，不补零。

关系复用原 `validate_indicator_explanation()`，重新检查请求、事实、单位、日期及原精度比较，不仅依赖旧的“已通过”标志。最多展示8条已核对关系，超出明确提示非穷尽。模型或用户说“RSI偏低”，而原值为79.545455时，展示实际值与高于70的参考分区，不沿用错误前提。程序不据此解释为何发生某条新闻事件或推导未来涨跌。

## 5. 指标知识与展示契约

`parse_knowledge_question()`只匹配完整的有限定义表达，例如：

- `RSI是什么`、`RSI超卖是什么意思`。
- `解释一下MACD里的DIF和DEA`。
- `SMA和EMA分别是什么`、`20日均线是怎么计算的`。

定义与项目计算口径一致：SMA初始化EMA、Wilder RSI/ATR、BOLL总体标准差、MACD柱值2×(DIF−DEA)、严格此前窗口量能倍率。含额外股票、日期或交易要求的句子不能截取前半句当作纯知识问题。

明确知识问题0次模型、0次行情；无研究结果也可回答。超出此语法不保证直接回答，仍可能进入原意图理解并说明限制。当前没有知识来源检索和自由生成的通用教学答案。

`AgentTurnResult`新增 `knowledge_answer` / `followup_answer`，`display_answer`仅显示程序答案。追问不把缓存填进本轮 `research_result`，因此不会把历史展示统计成一次新分析。`followup_answer.validation_scope`明确仅检查保存字段和有限关系；原 `answer_validation=not_performed` 保持，不能冒称任意自由文本已被验证。

## 6. 终端运行与额度

先运行无需凭据的固定离线连续演示：

```powershell
$env:PYTHONPATH='src'
.\.venv\Scripts\python.exe -X utf8 -B -m trading_companion.followup_demo
```

自动执行研究、RSI追问、DIF/DEA定义、SMA修改、`/last`和退出。它是有限Fake脚本，不能自由聊天；共4条计入输入的问题、6次Fake模型调用、2次实际人工CSV分析，没有真实请求。

自己输入时，仍需在已配置模型的终端显式启动：

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m trading_companion.agent_cli --provider deepseek --data synthetic
```

此路径可能付费，行情仍是人工样例，本步未代用户运行。启动需有模型配置；运行后精确知识问题或 `/last` 本身不发模型请求。保持原每次启动5条非空问题、15次模型转发的上限：普通追问和知识问题计入输入，`/last`等斜杠命令不计入、不补充额度。自然追问最多1次模型/0次行情；明确历史查看0/0；指标修改仍是新研究，最多2次模型/1次分析。
